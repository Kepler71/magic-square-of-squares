# Продолжение: все 179 наклонов со знаменателем до 24 исключены

Дата: 2026-09-13. Это продолжение локального проекта по магическому квадрату квадратов. Результат относится к рациональным линейным сечениям q=kp общей нормированной модели, а не к перечню G1(m,n). Два списка сечений нельзя отождествлять.

## Утверждение и область действия

Рассматриваем

```
1+p     1−p−q   1+q
1−p+q   1       1+p−q
1−q     1+p+q   1−p
```

Для девяти различных положительных рациональных квадратов посредством поворотов/отражений можно выбрать 0<q<p, p+q<1. Положим k=q/p, 0<k<1.

**В сокращённой дроби k знаменатель должен быть не меньше 25.** Исключены все 179 возможных рациональных k с меньшими знаменателями. Для каждого такого k проверка охватывает ВСЕ рациональные p, без ограничения высоты и размера целых корней.

Это необходимое условие для полного квадрата. Оно не утверждает существование решения при больших знаменателях, не определяет «место решения», не закрывает весь класс G1(15,8) и не изменяет автоматически его QC-список. Историческая новизна результата не проверялась.

## Первый этап: три клетки

Для коэффициентов a,b,c из {±1,±k,±(1+k),±(1−k)} необходима рациональная точка

```
Y²=f(p)=(1+ap)(1+bp)(1+cp).
```

Пусть f=A p³+B p²+C p+1. Проверенная замена X=A p,V=A Y даёт

```
V²=X³+B X²+A C X+A².
```

Для каждого наклона перебирались до 56 различных троек. При ранге 0 перечислялись ВСЕ рациональные точки эллиптической кривой, восстанавливались все конечные p=X/A и проверялись девять клеток. Исключение фиксировалось только после полного провала положительности, различности или индивидуальной квадратности во всех точках.

У семи наклонов все 56 кубических кривых имели положительный ранг по PARI (границы совпали). Поэтому один только этот этап их не исключил:

```
4/15, 7/24, 9/22, 11/19, 13/22, 17/24, 22/23.
```

Это не кандидаты на найденный квадрат: это сечения, для которых выбранное семейство необходимых условий не дало конечного списка точек.

## Второй этап: четыре клетки

Для четырёх коэффициентов c_i требуется

```
Y²=∏(1+c_i p).
```

У квартики есть рациональный корень r=−1/c_1. Положим

```
x=1/(p−r), w=Y/(p−r)²,
w²=g(x)=c_1 ∏_{i=2}^4 ((1−c_i/c_1)x+c_i).
```

Если g=A x³+B x²+C x+D, то X=A x,V=A w даёт эллиптическую модель

```
V²=X³+B X²+A C X+A²D,
p=r+A/X.
```

Все замены проверены символически. Точка O эллиптической кривой даёт p=r, где одна клетка нулевая; она проверена и исключена. X=0 соответствует p=∞ и не даёт конечный нормированный квадрат с центром 1. Таким образом, исключённые карты не теряют положительных решений.

С точки зрения интегралов преобразование столь же точное: dX/V=dx/w=−dp/Y. Для кубического этапа dX/V=dp/Y. Интегральная зависимость связана с той же алгебраической кривой, рациональные точки которой проверяются.

## Сертификаты и независимые проверки

Для всех 168 новых свидетелей:

1. PARI ellrank дал нижнюю и верхнюю границы [0,0]. eclib two_descent независимо дал rank=rank_bound=0, certain=True. Аналитический ранг и BSD не использовались.
2. Все рациональные точки кручения исходной модели предъявлены. Их полнота обоснована хорошей редукцией: НОД точных #E(F_l) совпадает с количеством предъявленных точек. В 167 случаях их 8, при k=9/16 их 16.
3. Отдельный скрипт без Sage, только Python Fraction, заново проверил коэффициенты кривых, принадлежность всех точек, замкнутость их группы, уничтожение умножением на порядок группы, количества точек над конечными полями, восстановление p и все девять клеток. Проверены 168/168 сертификатов.
4. Отдельно проверены все 168 рациональных изоморфизмов между исходными и минимальными моделями: прямая подстановка (u,r,s,t) в уравнения даёт тождество. Проверено, что все использованные простые дают хорошую редукцию.
5. Spark отдельно проверил арифметическую часть 34 сертификатов диапазона 7–12, несоответствий не сообщил. Это не третий пересчёт ранга.

Особый случай k=9/16 подчёркивает необходимость подъёма: у кривой кручение порядка16, и значение p=−8/15 даёт положительные разные клетки, но только центр квадратен. Квадратность произведения трёх клеток не заменяет их индивидуальную квадратность; эта точка отброшена именно полным тестом.
