Начать проверку пакета:

```sh
sha256sum -c SHA256SUMS
python3 audit_40_43_pairing.py
python3 check_census.py
```

Старые отчёты отражают предыдущие этапы. В four_cell_25_48.json последняя строка 40/43 помечена unresolved на момент этого этапа; окончательное исключение содержится в exception_40_43_certified.json. Сводный census_through_48.json учитывает окончательные сертификаты.
