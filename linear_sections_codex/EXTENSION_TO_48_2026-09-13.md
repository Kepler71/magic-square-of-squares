# Линейные сечения: исключены все 711 наклонов до знаменателя 48

Дата: 2026-09-13. Продолжение EXTENSION_TO_24_2026-09-13.md. Старые отчёты сохраняют результаты соответствующих этапов; актуальная граница приведена здесь.

## Результат и его точный смысл

Нормированный магический квадрат имеет вид

```text
1+p     1−p−q   1+q
1−p+q   1       1+p−q
1−q     1+p+q   1−p
```

Если исходные клетки — девять различных положительных рациональных квадратов, деление на центральный квадрат сохраняет квадратность. Повороты и отражения позволяют выбрать 0<q<p; положительность требует p+q<1. Положим k=q/p.

**Для возможного решения знаменатель сокращённой дроби k должен быть не меньше 49.** Все 711 рациональных k между 0 и 1 со знаменателем ≤48 исключены. Для каждого фиксированного k исключение охватывает все рациональные p, без ограничения высоты.

Это необходимое условие, полученное точными вычислениями. Оно не доказывает существования полного квадрата и не решает общую задачу. Наклоны k=q/p не следует отождествлять с индексами G1(m,n) или классом (−15,2,−30): для переноса результата туда нужна явная формула отображения. Историческая новизна этой границы не установлена.

## Связь с предложением о сечениях и интегралах

Для фиксированного k коэффициенты восьми нецентральных клеток лежат в {±1, ±k, ±(1+k), ±(1−k)}. Если каждая клетка квадратна, произведение любых трёх или четырёх клеток тоже квадрат. Это даёт необходимые эллиптические условия.

Для трёх коэффициентов:

```text
Y² = (1+ap)(1+bp)(1+cp) = A p³+B p²+C p+1,
X=A p, V=A Y,
V²=X³+B X²+A C X+A²,
dX/V=dp/Y.
```

Для четырёх коэффициентов c_i положим r=−1/c_1:

```text
Y²=∏(1+c_i p), x=1/(p−r), w=Y/(p−r)²,
w²=c_1 ∏_{i=2}^4 ((1−c_i/c_1)x+c_i)=A x³+B x²+C x+D,
X=A x, V=A w,
V²=X³+B X²+A C X+A²D,
p=r+A/X, dX/V=−dp/Y.
```

Так получается точная связь интегральной формы с алгебраической кривой. Арифметическое ограничение возникает при определении её рациональных точек. При ранге 0 перечисляется вся группа кручения, затем восстанавливаются p и проверяются все девять отдельных клеток. Квадратность произведения сама по себе недостаточна. Точки вне аффинной карты учтены: O даёт p=r с нулевой клеткой, X=0 даёт p=∞.

## Последний случай k=40/43

Выбраны коэффициенты (40/43,83/43,−40/43,−83/43):

```text
Y²=(1−(40p/43)²)(1−(83p/43)²).
```

Минимальная эллиптическая модель:

```text
E: y²=x³+x²−68110640 x+204180681300.
```

PARI ellrank дал [0,0,2,[]], то есть точный ранг 0. Обычный 2-спуск eclib дал интервал [0,2] и размерность 2-группы Селмера 4. Это различие силы границ, а не противоречие. По документации PARI ellrank использует, в частности, информацию о спаривании; нулевая верхняя граница здесь не является предположением BSD. [Документация PARI](https://pari.math.u-bordeaux.fr/dochtml/ref-stable/Elliptic_curves.html#ellrank).

Для отдельной проверки использована реализация формулы Фишера из проекта Claude, сохранённая в vendor/ctp_quartic.sage. Две бинарные квартики, полученные как кандидаты через PARI ell2cover:

```text
g1 = 513 x⁴ −6912 x³z +23794 x²z² +99072 xz³ +105393 z⁴,
g2 = 13801 x⁴ −15936 x³z −14894 x²z² +15936 xz³ +13801 z⁴.
I=3269310736, J=−352863449015168.
```

Для них построена третья квартика, представляющая сумму классов. Проверены общие инварианты, локальная разрешимость всех трёх квартик и тождество m²=z(g1)z(g2)z(g3) в кубической алгебре. Спаривание вычислено в обоих порядках: каждый раз произведение локальных символов Гильберта равно −1, то есть значение спаривания ненулевое. Формула и связь ядра спаривания с 4-спуском — теоретический вход из работы Фишера. [Tom Fisher, On binary quartic forms and the Cassels–Tate pairing](https://arxiv.org/abs/2208.14977).

Ненулевое знакопеременное спаривание имеет ранг не меньше 2. У E все точки 2-кручения рациональны, размерность E(Q)[2] равна 2. Поэтому

```text
rank E(Q) ≤ dim Sel₂(E) − dim E(Q)[2] − rank pairing
          ≤ 4 − 2 − 2 = 0.
```

Отдельный скрипт на Fraction/SymPy заново вычислил все 22 локальных символа по явным формулам, проверил локальные свидетели, покрытие плохих простых, алгебру формулы и изоморфизм якобиана с E. Это отдельная реализация арифметической проверки того же теоретического метода. Размерность группы Селмера 4 остаётся результатом eclib; этот аудитор её заново не вычисляет. Сертификат сохраняет исходную границу eclib [0,2], не подменяя её результатом [0,0].

Все восемь рациональных точек кручения предъявлены. Полнота подтверждена хорошей редукцией; #E(F_7)=8. После обратного преобразования все конечные значения параметра:

```text
p ∈ {−43/40, −43/83, 0, 43/83, 43/40}.
```

Ни одного значения в требуемом интервале 0<p<43/83 нет. При p=0 все клетки совпадают; граничные значения дают нулевые клетки. Таким образом, этот наклон исключён полностью.

## Статус обоснований

- **Точные алгебраические выводы:** нормировка, необходимые произведения клеток, рациональные замены координат, равенства дифференциалов, обратный подъём и проверка всех девяти клеток.
- **Строгие результаты CAS:** нулевые верхние границы алгебраического ранга; для последнего случая — размерность Селмера из eclib плюс точное спаривание. Аналитический ранг и BSD не используются. Вывод зависит от корректности реализаций CAS и применённых теорем.
- **Дополнительный аудит:** 532 новых сертификата проверены рациональной арифметикой; для всех 532 проверены тождества изоморфизмов и хорошая редукция. Последний случай дополнительно имеет аудит 22 символов и трёх локально разрешимых квартик. Полнота списка 711 проверена отдельно.
- **Открыто:** общая задача, оставшиеся направления, историческая новизна границы, явная связь новых сечений с текущими кривыми G1/Q/E±. Локальный аудит не является формальной верификацией всей библиотеки eclib или доказательством общего запрета.

## Следующая содержательная задача

Вывести из свидетелей семейства условий на числитель и знаменатель k, при которых хотя бы одно произведение трёх/четырёх клеток имеет ранг 0 и не допускает подъёма. Исследовать зависимость 2-спуска от квадратных классов выражений в k. Одновременно выписать k=q/p в координатах оставшейся модели G1: только это позволит понять, исключает ли новый фильтр её конкретные кандидаты. Продолжение численной границы само по себе общей теоремы не даёт.
