### 1.1 Теорема о ранге используемых точек (Codex, UNIFIED §3; исходная форма — Claude, RESULT_RANK_TWO шаг 5)

**Формулировка.** b ∈ ℚ*, P−, P0, P+ ∈ 2E_b(ℚ) — конечные точки с тремя различными x в арифметической прогрессии. Тогда
rank⟨P−,P0,P+⟩ ≥ 2, а значит rank E_b(ℚ) ≥ 2. То же для E_c.
**Статус: доказано (лит.).** Четыре проверки, опровержения нет.

Цепочка опор. Её надо указывать целиком; до сих пор не указывала ни одна записка.
- Voutier–Yabuta, Acta Arith. 151 (2012) 165–190, Thm 1.3(ii). Модель y² = x³ + ax, a без четвёртых степеней, P бесконечного
  порядка, n чётно. Если у B_n нет примитивного делителя, то n ≤ 2. Условия на x(P) касаются только нечётных n. Формулировку
  сверили три проверяющих: один по своей копии PDF, двое по копиям из пакета Codex. Внутри доказательства VY:
  - n = 2^k: Yabuta 2009, Exp. Math. 18, Thm 1.2 (y² = x³ + Ax, покрывает A = −N²; формулировка сверена по PDF);
  - 4 ≤ n ≤ 20: Ingram 2007, §3. **Этот текст никто в проекте не прочитал**;
  - компьютерный перебор 410 точек при |a| < 384;
  - 5 | n: лемма 5.1, ошибочная, её исправил Verzobio.
- Verzobio, arXiv:2001.09634v3, Thm 1.3: примитивный делитель есть при любом 5 | n. Внутри: лемма 3.1 (сведение к радикалу),
  n = 30 (Prop. 3.17, через PARI `thue`, см. §2.3 в), для n ≤ 25 — отсылка к VY и Ingram (нам из этих случаев нужен n = 10).

Шаги, которые подтвердили все четыре проверяющих.
- Переход «ранг 1 ⇒ P_j = 2m_jG» берётся через **насыщение** в свободной L = E_N(ℚ)/E_N[2], а не через образующую подгруппы H.
  У Codex сделано именно так. От выбора подъёма G результат не зависит.
- Кручение E_N(ℚ) = E_N[2]: Мазур, ψ₃ = 3x⁴ − 6N²x² − N⁴, x(2P) = ±N ⇔ (x² ∓ 2Nx − N²)² = 0. Численно подтверждено на 1824
  бесквадратных N ≤ 3000.
- Нормировка b = Nt² сохраняет 2E, прогрессию и rank H. Модель y² = x³ − N²x глобально минимальна (проверено при N ≤ 2000).
  В теореме VY единственное условие — a без четвёртых степеней, так что вопрос о минимальности снят. Порядок «сначала нормировать,
  потом применять VY» существенен: на немасштабированной модели примитивный делитель исчезал в 10 случаях из 10.
- |m_j| различны, поэтому максимум M единственен, M ≥ 3 и n = 2M ≥ 6. Разбор трёх позиций максимума верен, включая ℓ = 2
  в середине.

Численный контроль (проверено численно, это не доказательство): 671 направление на кривых ранга 1–3, n ≤ 32; 160 прямых, n ≤ 40,
547 200 расстановок; 11 122 пары (точка, n). Провалов примитивности 0, прогрессий среди x(2mG) 0.

### 1.2 Контроль совместимости UNIFIED §6 (b = 34, c = 3400)

rank E_34 = rank E_3400 = 2, rank E_3434 = 2, rank E_3366 = 1. **Доказано (ПО)** тремя путями:

## 4. Следующий шаг: одно направление

**Совместная ориентационная арифметика четырёх прямых через центр в ℤ[i]**: усилить теорему D, используя обе связи полного
квадрата одновременно (u_{b+c} = u_b + u_c и u_{b−c} = u_b − u_c). Это пункт (2) из center4 §9.

**Обоснование.**
- *D превращает концентрацию в противоречие.* Пусть все простые γ чисты на одной тройке и лежат в одном классе ориентаций. Тогда
  D даёт γ⁴ ≤ N_L·γ², то есть γ ≤ √N_L ≤ 2, а в примитивном квадрате γ ≥ 5. Значит, вся свобода гипотетического квадрата — в том,
  как простые γ распределены по классам ориентаций σ(p) ∈ {±1}⁴/± и по нечистым прямым (не больше одной на p по лемме §1.3 #3).
  Это конечная комбинаторика плюс одно архимедово неравенство на класс.
- *Одной D по тройкам мало.* Замечание сводки, проверено вручную, это модель весов, а не теорема о квадратах. Введём веса
  ω_p = log p^{2e_p} / log γ², Σω_p = 1. D требует от каждого класса каждой из четырёх троек вес ≤ 1/2 + O(1/log γ). Если
  распределить вес поровну по 8 классам {±1}⁴/±, класс тройки получает 1/4 < 1/2: система совместна. Поэтому новое звено обязано
  связывать тройки. Кандидат — две сравнимости Z₁ ≡ Z₂ ≡ 0 (mod ∏π_p^{2e_p}) с общими ξ_b, ξ_c, прогноз center4 §9.
- *Альтернативы упираются в отсутствующую теорему.* На стороне E_b ранг 3 требует аналога Зигмонди для эллиптических сетей ранга 2.
  В литературе его нет (§1.4 #5, #10; UNIFIED §7). По lattice2d, без вердикта, он сводится к (Z2).
- *Дёшево и с контролем.* Счёт — гауссовы нормирования. Положительные контроли для утверждений о тройках уже есть: 3375 конфигураций
  до 10⁹ и Саллоус (центр 1105, три класса). Всякое новое утверждение о тройке обязано на них выполняться. Отрицательный контроль —
  случайные тройки без связи (35–53 % нарушают D). Для утверждений именно о четырёх прямых положительного контроля нет, это
  ограничение метода, и его надо держать в уме.

**Первые шаги.**
- (0) Codex: независимая по правилу 8 проверка доказательства теоремы D (center4 §5, одна страница). Это условие, без которого
  дальше не строить.
- (1) Записать систему: z_u ∈ ℤ[i], N(z_u) = γ², u = Im z_u² для u ∈ {b, c, b+c, b−c}, плюс две связи. В каждом p — вектор
  ориентаций или одна нечистая прямая. Вывести совместную сравнимость для Z₁ и Z₂ и оценку для их комбинаций.
- (2) Цель минимум — константа в D2 меньше 2 и запрещённые наборы классов в {±1}⁴. Цель максимум — лемма «некий класс некой
  тройки несёт вес > 1/2», которая даёт противоречие.
- (3) До начала сверить шапку и §1 `PROOF_PROGRESS_LIFT_CLASSES_2026-09-26_FROM_CODEX.md`. Его остаточные классы d_T, d_L
  ограничены простыми ≡ 1 (mod 4) из r ± s; возможна стыковка с классами ориентаций, но это не проверено.
