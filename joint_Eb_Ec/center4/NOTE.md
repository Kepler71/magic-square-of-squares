## 1. Что такое «общий центр»

Клетки a + ib + jc при i, j ∈ {−1,0,1} — это a, a ± b, a ± c, a ± (b+c), a ± (b−c). Условие «a — x-координата точек в
2E_b, 2E_c, 2E_{b+c}, 2E_{b−c}» означает квадратность a, a ± u для u ∈ {b, c, b+c, b−c}, то есть **всех девяти клеток**. Значит,
угол «общий центр» — не ослабление, а переформулировка всей задачи: строки квадрата (три точки на E_b) вытекают из четырёх
прямых через центр и наоборот. **Доказано (тривиально).**

В магическом квадрате Лукаса шаги b, c стоят на диагоналях, b ± c — на средних строке и столбце. Любые три из четырёх прямых через
центр дают 7 квадратов: {b, c, b+c} — это «магические песочные часы» Бьюэлла (две диагонали и средний столбец, открытая задача),
{b+c, b−c, c} — крест и одна диагональ; шесть клеток семилинейного квадрата Саллоуса вне главной диагонали — ровно этот второй тип,
но с **неквадратным** центром a = 4420.

**Размерности и роды (доказано (ПО), `geometry.py`).** Многообразие V ⊂ P⁸ — поверхность (6 квадрик, общий тип, p_g = 111 по Auel–Singer).
При фиксированном наклоне c/b — кривая, пересечение 7 диагональных квадрик в P⁸, степень 128, род 321 (Риман–Гурвиц для (ℤ/2)⁸-накрытия P¹
с 9 точками ветвления; ряд Гильберта 128t − 320 при c/b = 3/7 это подтверждает). При фиксированном b/a — род 49. Кривая
D₄ = {y_u² = x(x² − u²), u ∈ {b,c,b±c}} (общий x только на уровне произведений) — род 25; её якобиан по характерам (ℤ/2)⁴ распадается
на E_b, E_c, E_{b+c}, E_{b−c}, шесть кривых F_{u,v}: w² = (x²−u²)(x²−v²) (якобиан y² = X(X+(u+v)²)(X+(u−v)²), зависит только от наклона;
j(F_{b,c}) = 16(k⁴+14k²+1)³ / (k²(k²−1)⁴), k = c/b — проверено с Sage), четыре якобиана рода 3 вида w² = x∏_{u∈S}(x²−u²), |S| = 3,
и один рода 3 (|S| = 4). F_{u,v} входят в 126 эллиптических факторов кривой наклона, известных проекту; нового здесь нет.

## 2. Круговая группа общего центра

Пусть a ∈ ℤ_{>0} — общий центр (квадрат или нет), a ∓ u = α_u², β_u² (α_u, β_u > 0). Положим

    Ω_u = α_u β_u + i·u ∈ ℤ[i],   N(Ω_u) = a²,   w_u = Ω_u / a ∈ S¹(ℚ),   Im w_u = u/a.

При a = γ² это Ω_u = ω_u², ω_u = x_u + i y_u, x_u = (β_u+α_u)/2, y_u = (β_u−α_u)/2: прямоугольный треугольник (x_u, y_u, γ) с площадью u/4.
Группа S¹(ℚ) = μ₄ × ⊕_{p≡1(4)} ℤ·(π_p/π̄_p) — свободная бесконечного ранга; её класс по модулю квадратов w = ρ/ρ̄ ↦ N(ρ) mod ℚ*².
**Словарь (доказано):** u — допустимый шаг для центра a ⟺ u = a·Im w, где w ∈ S¹(ℚ) лежит в классе a; у квадратного центра все w_u —
квадраты в S¹(ℚ). Магический квадрат (a = 1): четыре точки z_k ∈ S¹(ℚ) с Im z₃² = Im z₁² + Im z₂², Im z₄² = Im z₁² − Im z₂².

Для простого p ≡ 1 (mod 4), e = v_p(a), π | p: v_π(Ω_u) + v_π̄(Ω_u) = 2e. Линия u **p-чистая**, если min(v_π Ω_u, v_π̄ Ω_u) = 0, то есть
p ∤ g_u := НОД(α_u, β_u); тогда Ω_u делится на π^{2e} (ориентация σ_u(p) = +1) или на π̄^{2e} (σ_u(p) = −1). Целочисленно:
σ_u(p) = +1 ⟺ α_uβ_u + ι·u ≡ 0 (mod p) при фиксированном ι² ≡ −1 (mod p). Числа v_π(w_u) = v_π(Ω_u) − e — «координаты» w_u.

Это «двойственная» сторона к рангу E_b: там фиксирован шаг b и меняются центры a + jc (три точки в 2E_b), здесь фиксирован центр
и меняются шаги (точки w_u в S¹(ℚ)). В обоих случаях ранг ≥ 2 выводится одинаково: единственный «крайний» член не может сократиться
(там — примитивный делитель, здесь — гауссово простое центра).

## 3. Лемма о двойном минимуме — доказано

**Лемма.** Пусть u₁, u₂, u₃ — шаги трёх прямых с общим центром a, Σ n_j u_j = 0, n_j ∈ ℤ \ {0}, p нечётно, p ∤ n₁n₂n₃. Тогда
min_j v_p(g_j) достигается не менее двух раз.

*Доказательство.* Если v_p(g_i), v_p(g_j) ≥ k, то p^{2k} | a ± u_i, a ± u_j, откуда p^{2k} | a, u_i, u_j; из связи p^{2k} | u_l, значит
p^{2k} | a ± u_l и v_p(g_l) ≥ k. ∎

*Следствие для квадрата.* Любые две из четырёх u ∈ {b, c, b+c, b−c} порождают над ℤ[1/2] все четыре. Поэтому в **примитивном**
квадрате каждое простое p делит **не более одного** из g_b, g_c, g_{b+c}, g_{b−c}: у каждого p | γ не больше одной «нечистой» прямой.

## 4. Теорема B (ранг ≥ 2 в круговой группе) — доказано

**Теорема B.** Для трёх прямых с общим центром a (квадратным или нет), ненулевыми клетками, связью Σ n_j u_j = 0 (|n_j| ≤ 4) и попарно
различными |u_j| подгруппа ⟨w₁, w₂, w₃⟩ ⊂ S¹(ℚ) имеет ранг ≥ 2 (по модулю μ₄).

*Доказательство.* Ранг 0: w_j ∈ μ₄, Im w_j ∈ {0, ±1}, то есть u_j = 0 или a ∓ u_j = 0 — исключено. Ранг 1: w_j = ε_j y^{k_j}, y ∈ S¹(ℚ)
неторсионно. Все w_j в одном классе (классе a); заменяя, если нужно, y на iy, добиваемся, чтобы все ε_j были одного типа ({±1} или
{±i}). Тогда |k_i| = |k_j| влечёт w_i = ±w_j^{±1} и |u_i| = |u_j|; значит, |k_j| попарно различны. Возьмём p | N(ρ), y = ρ/ρ̄,
v_π(y) = f ≠ 0. Тогда |v_π(w_j)| = |k_j|·|f| попарно различны и максимум достигается один раз; но |v_π(w_j)| = e − t_j, t_j = 2v_p(g_j),
то есть минимум v_p(g_j) достигается один раз — противоречие с леммой (p ≥ 5 > |n_j|). ∎

Второе, независимое доказательство (лемма Гаусса): при ранге 1 связь — многочлен Лорана с ≤ 3 членами и старшим коэффициентом ≤ 4 по
модулю, а минимальный многочлен y = ρ/ρ̄ примитивен со старшим коэффициентом N(ρ) или N(ρ)/2 ≥ 5; значит, многочлен тождественно нулевой,
что возможно лишь при вырождении.

**Следствия.** (i) Для каждой из четырёх троек прямых квадрата (связи b+c = b+c, b−c = b−c, (b+c)+(b−c) = 2b, (b+c)−(b−c) = 2c)
ранг ≥ 2, поэтому ранг ⟨w_b, w_c, w_{b+c}, w_{b−c}⟩ ≥ 2. (ii) Центр γ² примитивного квадрата (и песочных часов) не может быть квадратом
степени простого: при γ = p^k все w_u лежат в μ₄ × (π/π̄)^ℤ. Прямое доказательство: при γ = p^k чистая прямая — это ω = ε·π^{2k}
или ε·π̄^{2k}, у всех чистых прямых одно и то же |u| = |Im π^{4k}|, а по лемме чистых прямых хотя бы две. (iii) Сильнее, чем «у γ ≥ 2
простых»: векторы (v_{π_p}(w_u))_p трёх прямых не пропорциональны; так, γ = 5^k·13^k с ω_u ∈ ⟨π₅π₁₃, π̄₅π̄₁₃⟩ тоже исключено.

## 5. Теорема D (неравенство баланса) — доказано; новое необходимое условие

**Теорема D.** Пусть три прямые L с общим центром a связаны соотношением Σ_{u∈L} n_u u = 0, N_L := Σ|n_u| ∈ {3, 4} (типы (1,1,1) и
(1,1,2) по модулю), |u| попарно различны. Пусть P — множество простых p ≡ 1 (mod 4), в которых все три прямые p-чистые и векторы
ориентаций (σ_u(p))_{u∈L} совпадают с точностью до общего знака. Тогда

    Π_P² ≤ N_L · a,      Π_P := ∏_{p∈P} p^{v_p(a)}.

Для квадрата с центром a = γ²: ∏_{p∈P} p^{2v_p(γ)} ≤ √N_L · γ.

*Доказательство.* Выберем π_p | p так, чтобы первая прямая имела σ = +1 во всех p ∈ P; тогда σ_u(p) не зависит от p ∈ P. Для каждой
u ∈ L один из Ω_u, Ω̄_u (обозначим T_u, τ_u = +1, если T_u = Ω_u, иначе −1) взаимно прост со всеми π_p, а другой делится на
∏ π_p^{2e_p}; при этом T_u = ∏ π̄_p^{2e_p}·ξ_u, ξ_u ∈ ℤ[i], |ξ_u| = a/Π_P. Связь Σ n_u(Ω_u − Ω̄_u) = 2i·Σ n_u u = 0 даёт
Σ n_u τ_u T_u ≡ 0 (mod ∏ π_p^{2e_p}), а так как π̄_p взаимно просты с π_p,

    Z := Σ n_u τ_u ξ_u ≡ 0 (mod ∏_{p∈P} π_p^{2e_p}),    |Z| ≤ N_L · a / Π_P.

Z ≠ 0: три слагаемых одного модуля. При коэффициентах (1,1,1) их нулевая сумма требует углов 120°, то есть отношения e^{±2πi/3} ∉ ℚ(i);
при (1,1,2) равенство |v₁ ± v₂| = 2|v| даёт v₁ = ±v₂ = ±v₃, отсюда T_i = ±T_j, Im Ω_i = ±Im Ω_j и |u_i| = |u_j| — вырождение.
Итак, Π_P² = N(∏ π_p^{2e_p}) ≤ N(Z) ≤ (N_L a / Π_P)², то есть Π_P⁴ ≤ N_L² a². ∎

**Следствие D2 (новое необходимое условие для квадрата).** В примитивном невырожденном магическом квадрате из квадратов с центром γ²
для **каждого** простого p

    p^{2·v_p(γ)} ≤ 2γ    (и ≤ √3·γ, если все четыре прямые p-чистые).

*Доказательство.* По следствию леммы у p не больше одной нечистой прямой; три остальные образуют тройку со связью, N_L ≤ 4, P = {p}. ∎

Иначе говоря, никакая примарная компонента γ не может быть больше удвоенного произведения остальных. Отсюда снова «γ не степень
простого». Условие не следует из §4 UNIFIED_THEOREMS (там только ранги кривых шагов) и из известных условий (простые центра ≡ 1 (mod 4),
клетки ≡ 1 (mod 24), не менее четырёх треугольников с гипотенузой γ).

**Насколько оно режет (проверено численно, `d2_pruning.py`).** Среди γ ≤ 10⁷, у которых все простые ≡ 1 (mod 4) и ∏(2e_p+1) ≥ 9
(481 761 число), D2 исключает 401 963 (83,4 %), из них всего 16 — степени простых. Типичная причина: наибольший простой делитель
больше √(2γ). Например, γ = 65 исключено (13² = 169 > 130), γ = 5·13·17·2213 исключено (2213² > 2γ).

**Версия с классами (доказано, та же теорема).** Для каждой тройки L простые, в которых L целиком чистая, делятся на ≤ 4 класса ориентаций
(векторы в {±1}³ по модулю знака), и для каждого класса K выполнено ∏_{p∈K} p^{2v_p(γ)} ≤ √N_L·γ. Если все простые чисты на L, то классов
не меньше двух (иначе γ² ≤ √N_L·γ): это количественная форма теоремы B.

**Связь с кривыми шагов.** γ² = a — общая x-координата точек P_u ∈ 2E_u; в модели E_{N_u} это x = γ²/t_u². Теорема D — ограничение на
числитель общей x-координаты четырёх точек: его разложение на гауссовы простые должно быть «сбалансировано» с учётом ориентаций
треугольников. Ни одна из кривых E_u отдельно этого не видит: для одной прямой любой γ ≡ сумма двух квадратов допустим.

## 6. Корневые числа и чётность рангов

**Локальной связи нет (проверено численно, вывод доказан).** Для t ∈ ℚ* корневое число w(E_t) = +1 ⟺ N = sqfree|t| ≡ 1, 2, 3 (mod 8)
(по памяти, стандарт); оно зависит только от знака t и класса t в ℚ₂*/ℚ₂*². При центре 1 условие 1 ± u ∈ ℚ₂*² ⟺ v₂(u) ≥ 3
(`parity.py`, перебор); вещественное условие |b|, |c|, |b ± c| < 1 допускает любые знаки и любое отношение |b|:|c|. Перебор целых
B, C ≡ 0 (mod 8), |B|, |C| ≤ 480 реализует **все 16** наборов (w_b, w_c, w_{b+c}, w_{b−c}). Значит, из условий в ℝ и ℚ₂ (а только они
определяют корневые числа) никакое соотношение между четырьмя корневыми числами не выводится; ограничение, если оно есть, глобальное.

**Предложение P (доказано по модулю теоремы о 2-чётности, по памяти: Monsky 1996; Dokchitser–Dokchitser).** s₂(E) := dim Sel₂(E/ℚ) − 2
имеет чётность (1 − w(E))/2 и s₂ ≥ rank. Вместе с §4 UNIFIED_THEOREMS: при N_b ≡ 5, 6, 7 (mod 8) s₂(E_b) ≥ 3 (то же для c); при
N_{b±c} ≡ 1, 2, 3 (mod 8) s₂(E_{b±c}) ≥ 2. При конечности Ш[2^∞] (или гипотезе чётности) то же для рангов. Это простое следствие,
а не совместное условие.

**Контроль на Саллоусе (доказано (ПО), mwrank).** N_b = 210, N_c = 66, N_{b+c} = 1, N_{b−c} = 69; ранги 2, 0, 0, 1. Ранги E_c, E_{b+c}
равны 0 — ранговые условия «общего центра» у семилинейного квадрата нарушены. Так и должно быть: его центр a = 4420 не квадрат, и точка
с x = a лежит на скрученной кривой E_{a·u}, а не на E_u. Ранги скрученных E_{ac}, E_{a(b+c)}, E_{a(b−c)} равны 2, 2, 3.

## 7. Что известно в литературе (с пометкой, что читал)

- Магические «песочные часы» (7 квадратов: две диагонали, средний столбец и центр; в наших обозначениях прямые b, c, b+c) — Buell 1999,
  поиск без решений; Morgenstern 2011: их нет ⟺ множество {p(1−p²)/(1+p²)²} не замкнуто относительно сложения; Morgenstern 2014:
  ещё три безрезультатных поиска (страницы multimagie.com, прочитано). Задача открыта.
- Woll 2017 (прочитан целиком): гауссова параметризация песочных часов (z₁⁴ + z₂⁴ + z₃⁴ ∈ ℝ); ограничений на разложение центра нет.
- Rabern 2003 / Morgenstern 2015: простые делители центра ≡ 1 (mod 4), все клетки ≡ 1 (mod 24) — по пересказу Boyer и Википедии; сами
  статьи не читал. Morgenstern 2006 (прочитано): наименьшая клетка ≠ 1 — рост последовательности Пелля, приём «крайний член
  не сокращается», близкий к нашему.
- Cilleruelo–Granville 2006, §8 (прочитано): 3×3-прогрессия квадратов ⟺ тройка точек E_∆ с x(2P_i) в прогрессии, и «в [7] доказано, что
  ранг E_∆ ≥ 2»; [7] = Bremner–Silverman–Tzanakis, J. Number Theory 80 (2000). **Для всех:** ранговое условие RESULT_RANK_TWO, по-видимому,
  уже есть у BST 2000; сверить формулировку по самой статье (я видел только стр. 1 скана).
- Garcia-Fritz–Pasten 2026 (аннотации): доказанная гипотеза Бремнера — длинные x-прогрессии на E требуют большого ранга; к трём точкам
  не применимо.
- Утверждений вида «ранг ≥ 2 в S¹(ℚ)» или неравенства D я в просмотренном не нашёл. Новизна не утверждается; прошу Grok проверить
  Morgenstern 2015 «3x3 Magic Square of Squares Properties» и Robertson 1996.

## 9. Гипотеза и следующий шаг

**Гипотеза R3.** Для любых трёх прямых с общим центром и связью типов (1,1,1)/(1,1,2) ранг ⟨w₁, w₂, w₃⟩ равен 3. Свидетельства: 3375 из
3375 конфигураций до 10⁹, у всех ≥ 3 простых p ≡ 1 (mod 4) в центре; двухпростой поиск пуст. Следствие для квадрата: у γ не меньше
трёх различных простых делителей, ранг четырёх точек центра ≥ 3.

Что уже известно о ранге 2 (доказано, элементарно, в духе §4). Пусть m_j = (v_{π_p}(w_j))_p и Σ k_j m_j = 0, k ≠ 0. В простом, где все три
прямые чисты, вектор (σ_j(p)) ортогонален k; в простом с единственной нечистой прямой l выполнено |k_iσ_i + k_jσ_j| < |k_l|. Если все k_j ≠ 0
и есть хотя бы одно полностью чистое простое, то с точностью до перестановки |k₃| = |k₁| + |k₂|. Тогда прямые 1 и 2 чисты во всех простых,
а все полностью чистые простые лежат в одном классе ориентаций, и по теореме D их произведение не больше √(N_L a). Остальная часть центра
приходится на простые, где нечиста прямая 3. Если полностью чистых простых нет, то в каждом простом ровно одна нечистая прямая.
Противоречия отсюда пока нет. Нужна вторая, «двухчленная» сравнимость по π_p^{t_l(p)} и, вероятно, анализ кривых Лорана
Im(εY^{m₃}) = ±Im Y^{m₁} ± Im Y^{m₂} на торе (S¹)²; при малых m их род 0 или 1.

**Самое перспективное продолжение.** (1) Доказать R3 — это даст «≥ 3 простых в γ» и новые отсечения. (2) Для полного квадрата
использовать обе связи сразу: у каждого p ≥ 3 чистые прямые из четырёх и два сравнения Z₁ ≡ Z₂ ≡ 0 (mod π^{2e}) с общими ξ_b, ξ_c; ожидаю
усиление D (константа меньше 2 и совместные ограничения на векторы ориентаций в {±1}⁴). (3) Практически: D2 — дешёвый фильтр для
любых поисков центров, отсекает ~83 % кандидатов.

## 10. Не делать

- Не искать связи корневых чисел / квадратных классов b, c, b±c из локальных условий: их нет (§6).
- Не перебирать центры γ = p^k и вообще γ с p^{2v_p(γ)} > 2γ: исключены теоремой D.
- Не считать «ранг E_{b±c} ≥ 1» проверяемым на семилинейных квадратах: у них центр не квадрат (у Саллоуса ранг E_{b+c} = 0, и это правильно).
- Не выдавать наблюдение «ранг 3» за теорему: доказан только ранг ≥ 2.
- Не ссылаться на RESULT_RANK_TWO как на новый результат, не сверив BST 2000 (§7).
