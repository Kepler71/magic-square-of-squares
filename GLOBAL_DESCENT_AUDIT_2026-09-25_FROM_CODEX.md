# Семь линий: установленные общие ограничения на попытки спуска

25 сентября 2026. Для пользователя, Claude / Fable. Два независимых параллельных разбора, затем проверка формул основным агентом.

**Результат:** установлены общие запреты для двух предложенных механизмов связывания эллиптических точек и точные недостающие условия для третьего. Они действуют для всех рациональных параметров, но **не доказывают отсутствия магического квадрата**. Историческая новизна этих частных теорем не утверждается.

Исходная постановка сохранена: девять клеток a+ib+jc, i,j∈{−1,0,1}, являются положительными рациональными квадратами. Семь линий приводят к трем точкам P−,P0,P+∈2E_b(Q), E_b:y²=x³−b²x, с x=a−c,a,a+c. Последняя линия требует арифметической прогрессии этих координат. Групповое равенство точек из этого не следует.

## 1. Арифметическое среднее не может одновременно быть групповым

**Теорема.** Для любого b∈Q*, трех аффинных точек E_b(Q) с различными x-координатами a−c,a,a+c невозможно никакое равенство

    ±P− ±P+ = ±2P0.

Даже принадлежность точек подгруппе 2E_b для этой теоремы не нужна.

Формулы хорды и удвоения сводят необходимое условие, при a(a²−b²)c≠0, к

    v²=−t⁸+8t⁶−10t⁴−16t²+3,
    t=b/a, v=2(1−t²)c/a.

У этого уравнения нет решений в Q_3. При отрицательной 3-адической нормировке t ведущая единица равна 2 mod3; при нулевой — вся правая часть равна 2 mod3; при положительной, включая t=0 отдельно, она равна 3 mod9. В каждом случае квадрат невозможен. Если a=0 или a=±b, P0 имеет порядок 2, и предложенное равенство сразу противоречит различию крайних x.

Это элементарное доказательство, не зависящее от рангов, высоты координат или ограничения перебора. Подробности — `agent_relation/MIDPOINT_FORBIDDEN.md`.

Дополнительная независимая CAS-проверка: эллиптический фактор

    Y²=X³−40X²+384X−1024

имеет ранг 0 и точки только O,(8,0). Sage/mwrank и PARI дали одинаковый вывод. Эта проверка подтверждает, но не требуется для аргумента mod3/mod9.

**Следствие для проекта:** нельзя получить восьмую линию, просто объявив P0 групповой серединой P− и P+. Такой дополнительный мост несовместим с исходной арифметической прогрессией.

## 2. Синхронное деление пополам не дает спуска — при любых перестановках

Первое препятствие: из P∈2E_b(Q) не следует P∈4E_b(Q). Поэтому рациональная половина точки не обязана снова давать три рациональных квадрата. Пример на E_6:

    P=(25/4,−35/8)=2(12,36).

Четыре половины имеют x=12,−3,18,−2; ни одна не дает трех квадратов x−6,x,x+6. Это пример для повторяющейся конфигурации, а не контрпример невырожденному квадрату.

Есть более сильный общий запрет, не опирающийся на этот пример.

**Теорема.** Пусть девять ненулевых чисел m+id+jb, i,j∈{−1,0,1}, являются рациональными квадратами, b,d≠0. Для точек Q−,Q0,Q+ на E_b с x=m−d,m,m+d три числа x(2Q−),x(2Q0),x(2Q+) не образуют арифметической прогрессии **ни в каком порядке**.

Причина арифметическая. Из квадратности x−b,x,x+b следует v_3(b)>v_3(x). Применяя это к девяти клеткам, получаем

    v_3(b)>v_3(m), v_3(d)>v_3(m).

После общего масштабирования m — 3-адическая единица, а b,d делятся на 3. Формула удвоения раскладывается точно:

    φ_b(u)=x(2Q)=u/4+3b²/(4u)+b⁴/[u(u²−b²)].

Все знаменатели при u=m,m±d являются 3-адическими единицами. Для прежней середины дефект Δ0=φ(m−d)+φ(m+d)−2φ(m) имеет точную нормировку

    v_3(Δ0)=1+2v_3(b)+2v_3(d).

Для любого из двух других выборов середины дефект имеет нормировку

    1+v_3(d).

Они конечны, поэтому ни один дефект не нулевой. Подробное доказательство с оценкой остатков — `agent_descent/ALL_PERMUTATIONS_HALVING.md`.

Эта теорема охватывает выборы половин, знаков, 2-кручения, перестановку трех троек и последующее общее рациональное масштабирование. Следовательно, **именно этот** механизм не может превратить гипотетический полный квадрат в меньший полный квадрат.

Ограничение относится к удвоению/делению на одной семье E_b и указанной конструкции клеток. Произвольные иные соответствия между поверхностями оно не исключает. Оно также не утверждает, что исходного квадрата вообще нет.

## 3. Суммы и разности сохраняют шесть квадратов, но требуют трех новых условий

Для P±=(a±c,y±) точные формулы:

    x(P+±P−)=[a(a²−b²−c²)∓y+y−]/(2c²).

Если исходные точки принадлежат 2E_b(Q), их сумма и разность тоже принадлежат этой подгруппе. Поэтому шесть новых клеток действительно являются квадратами. Новый центр должен равняться

    A'=a(a²−b²−c²)/(2c²).

Обозначив κ=a(a²−b²−c²)/2, получаем точный критерий для недостающей третьей тройки:

    κ, κ−bc², κ+bc² ∈ Q².

**Эти условия не следуют универсальной алгебраической формулой из девяти исходных корней.** В общем функциональном поле девяти корней три новых квадратных класса независимы. Свидетели — три разных неприводимых дивизора

    a²−b²−c²,
    a(a²−b²−c²)−2bc²,
    a(a²−b²−c²)+2bc².

Исходные девять линейных радикандов по этим дивизорам — единицы. Расширение добавлением их корней неразветвлено, а нормировка соответствующего нового радиканда нечетна. Поэтому присоединение всех трех новых корней в общем случае имеет степень 8.

Это препятствие относится к общей рациональной формуле конкретного преобразования. Оно не запрещает специальные рациональные точки, где три дополнительные условия выполнены.

Локальный контроль: при a=1011,b=1,c=4 все девять клеток различны и положительны над R, а их корни существуют в Q_1009. Но новый центр — квадратичный невычет по модулю 1009. Это не рациональный контрпример исходной задаче: исходные корни здесь установлены над Q_1009, а не над Q.

Даже если три дополнительных условия выполнены, уменьшение рационального центра требует a²<b²+3c². После очистки знаменателей еще нужно доказать уменьшение **примитивного целого** инварианта. Ни одно из этих требований нельзя пропускать.

## 4. Дополнительные проверки и их правильный статус

- Общий ненулевой сдвиг всех трех точек на 2-кручение не сохраняет арифметическую прогрессию x. Точные вторые разности записаны в `torsion_and_squareclass.json`; для всех трех сдвигов они ненулевые при отсутствии полюсов и c≠0.
- Без условий квадратности кривая совместимости двух прогрессий при удвоении с обменом центра имеет род 17, а фактор по смене знаков — род 8 (точный расчет Sage/Singular). Файлы `agent_descent/relabeling_*`.
- В ограниченном поиске на этой кривой проверены 115290 пар без подходящих точек. Этот перебор не доказывает полноту. Для квадратного лифта теперь имеется более сильный локальный запрет из §2; продолжать поиск на этой кривой ради такого спуска не требуется.
- Конечнополевые примеры и вычисления ранга не используются как вероятностные доказательства. Основные запреты §§1–2 имеют явные арифметические доказательства.

## 5. Что остается для общего решения

Мы не установили искомый глобальный спуск и не доказали отсутствие магического квадрата. Вместо этого строго исключили два конкретных способа его построения и определили три недостающих условия третьего. Это ограничивает выбор дальнейших конструкций, но не заменяет доказательства исходной задачи.

Следующее содержательное направление — соответствие, которое меняет параметры b,c и сохраняет все девять квадратных условий одновременно. Для любого кандидата нужны три отдельные проверки:

1. Алгебраическое сохранение всех девяти корней, а не только их произведений или шести клеток.
2. Отсутствие локального препятствия сохранению восьмой линии, включая нормировки по 3.
3. Строгое уменьшение положительного целочисленного инварианта после нормировки к примитивным целым данным.

Если кандидат сводится к синхронному делению на два либо групповому среднему, настоящий пакет уже исключает его. Если он использует сумму/разность, нужно отдельно обеспечить три условия на κ. Без этого называть преобразование спуском нельзя.

Для Claude / Fable: независимо проверить прежде всего арифметические доказательства §§1–2. Не переносить их на утверждение «магический квадрат не существует» и не повышать статус остальных наклонов. Результат 126/451 остается отдельным доказанным частным случаем.
