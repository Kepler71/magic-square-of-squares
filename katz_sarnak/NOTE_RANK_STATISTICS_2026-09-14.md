# Статистика рангов: проверка идеи пользователя (Кац–Сарнак)

**Идея.** Если ранг семейства «прыгает» на числах Фибоначчи — это сигнал скрытой симметрии; распределение рангов по семейству
управляется типом симметрии L-функций (Кац–Сарнак; «минималистская» гипотеза: w = ±1 поровну, ранг 0 или 1 почти всегда, ранг ≥ 2 — доля 0).

**Посчитал** (`family_stats.py`, `family_250.json`): семейство E_k: y² = (1 − rz)(1 − (s − r)z)(1 − sz) — общий ранг над ℚ(k) равен 0,
все взаимно простые 0 < r < s ≤ 250, r ≠ s/2; 19 022 кривых; PARI `ellrank`, корневое число.

Нарушений чётности (ранг против w) при определённом ранге — 0. — проверено численно (w и ранги — строго).

**Избыток ранга 2 при w = +1** — главная аномалия. Он растёт с числом различных простых в r·s·(s − r)·(s + r):

Условие «s + r — квадрат» даёт 0,293 (335 кривых), «r·s — квадрат» — 0,067 (45). — наблюдение.

**Фибоначчи.** Внутри семейства (s ≤ 250): ранги 0,0,0,0,0,0,1,2,0,0 — одна «двойка» на (55, 89). В отдельной серии C_k (fibonacci/):
ранг 2 при k = 8 и k = 30 (ellrank [2,2]), при k = 41, 43, 45, 47 не определён ([0, 2], L(E,1) не считается — кондукторы ~10¹⁸).
Доля 2 из ~22 значений с w = +1 — в пределах общей частоты 20–25 %. **Специфического эффекта Фибоначчи не видно.** — наблюдение.

## Интерпретация (осторожно)
- Равное деление корневых чисел и ранг 1 при w = −1 согласуются с ортогональной симметрией.
- Растущая доля ранга 2 — известный «избыток ранга» в данных малой высоты (Bektemirov–Mazur–Stein–Watkins; Miller для однопараметрических
  семейств — по памяти). Здесь он сильно коррелирует с числом плохих простых: больше простых → больше 2-Селмер → чаще ранг 2.
  Предельная доля по гипотезе должна уйти в 0, но на наших высотах этого не видно. Структурного объяснения (скрытой второй точки над
  расширением ℚ(k)) не искали.
- Для переписи это объясняет, почему одного семейства не хватает: у четверти наклонов с w = +1 основная кривая имеет ранг 2,
  а у половины w = −1; закрывают другие кривые — и чем больше кривых, тем реже все сразу оказываются положительного ранга.
- Собственно Кац–Сарнак (распределение нижних нулей) не проверено.

## Не делать
- Не объявлять «эффект Фибоначчи»: на данных его нет.
- Не считать L(E,1) для C_k при k ≥ 30 через `L_ratio` — переполнение `anlist`.
