Пять голоморфных дифференциалов C7:

    dt/(u0u4), dt/(u0u8), dt/(u4u8),

Это уже даёт строгий смысл прежней идее интегралов. Для оставшихся пар ранги Jac(C7) равны 11,7,12, а Jac(H) — 6,4,4 в порядке (13,8),(15,8),(16,5). Поэтому исходный план не стал универсальным готовым QC-решателем. Проверенная достаточная граница r(C7)≤10 проходит только у (15,8); сама граница ещё не даёт реализации или списка точек. Для H простая граница r<4 не проходит у всех трёх.

## Как старый и новый мост соединяются

Пусть

    s=(m²+n²)/2,
    F0=m²+n²t², F4=s(1+t²), F8=n²+m²t²,
    L=F4−2mnt, U=F4+2mnt.

Общий объект для всех девяти клеток — гладкая нормализация W:

    u0²=F0, u4²=F4, u8²=F8, uL²=L, uU²=U.

Связи:

    W -> C7 -> H -> E_b
    W -> Qplus:  wplus²=F0F8 -> B
    W -> Qminus: wminus²=LU -> Bminus = B^(-1).

Общий t сохраняется. На W поднимаются обе формы dt/(u0u8) и dt/(uL*uU); они относятся к разным характерам смен знаков. Нельзя объявлять эти интегралы равными только из-за общего параметра. Старая C7 сама по себе не содержит uL,uU; новый фактор не является автоматически её фактором.

При m>n>0 пять квадратных классов независимы, их десять геометрических ветвей различны. W имеет степень 32 над прямой и род 49 по Риману–Гурвицу. Поэтому план не состоит в том, чтобы сразу считать весь её якобиан. Используем малые проекции и проверяем полный подъём. Одновременное существование точек на B и Bminus без согласования t и отдельных квадратностей также недостаточно.

## Обе диагонали теперь имеют общую формулу карты

Для квартики

    w²=a²t⁴+c t²+a²

используем эллиптическую модель

    Y²=X[(X−c)²−4a⁴],
    X=2a(w+a)/t²+c, Y=2aX/t,
    t=2aX/Y, w=(X−c)t²/(2a)−a.

Общая алгебраическая проверка:

    Y²−X[(X−c)²−4a⁴]
      = (4a²X/t⁴)·(a²t⁴+ct²+a²−w²).

При дифференцировании на квартике получаем dX/Y=−dt/w. Тождество работает для обеих диагоналей с их собственными w.

Параметры:

| Карта | a | c | Эллиптическая кривая |
|---|---|---|---|
| Qplus, произведение F0F8 | mn | m⁴+n⁴ | B: Y²=X(X−d)(X−(d+h)) |
| Qminus, произведение LU | s | 2s²−4m²n² | Bminus: Y²=X(X−d)(X+h) |

Здесь d=(m²−n²)², h=4m²n². Особые точки: O и (0,0) соответствуют t=0,w=±a; два других рациональных 2-кручения соответствуют двум ветвям t=∞.

Это закрывает ранее оставленную задачу явной карты старого B для (15,8). Теперь обе карты реализованы в одном стандартном Python-модуле.

## Что реализовано и проверено сейчас

nine_cells.py использует только Fraction, целочисленный isqrt и стандартную библиотеку. Он:

1. Восстанавливает t,w из точки B или Bminus, включая t=0 и отдельный статус бесконечности.
2. Проверяет принадлежность точки кривой и обратимость карты на конечной области.
3. Строит матрицу

       [ F0          (mt+n)²     L        ]
       [ (mt−n)²     F4          (m+nt)²  ]
       [ U           (m−nt)²     F8       ].

4. Проверяет все девять квадратностей, все восемь магических сумм, положительность и различность.
5. Если все клетки — рациональные квадраты, очищает знаменатели **корней**, делит на общий НОД корней и получает примитивную целую матрицу. Повторения остаются основанием отклонить решение.

run_controls.py: 18 контрольных параметров, 36 переходов туда-обратно, 12 особых ветвей на бесконечности. Проверены t↔−t и t↔1/t с необходимым масштабированием. При (15,8),t=±1 получаются девять квадратов с повторениями; обе точки отклоняются как невырожденное решение.

map_gate_points.py использует Sage только для группового сложения и изоморфизма моделей. Для каждой пары берёт kG+T при k=−2,…,2 и всех восьми точках кручения. Проверку подъёма выполняет модуль на обычном Python.

| Пара / выбранная кривая | Конечные точки | Бесконечные ветви | Девять квадратов, включая вырождения | Пригодное решение |
|---|---:|---:|---:|---:|
| (13,8), Bminus | 38 | 2 | 0 | 0 |
| (15,8), B | 38 | 2 | 4 | 0 |
| (16,5), Bminus | 38 | 2 | 0 | 0 |

Итого 120 точек эллиптических кривых. Это **контроль реализации**, не новый содержательный предел поиска; различные точки могут давать одно t. Полнота бесконечной группы и насыщенность G данным тестом не установлены.

## Следующий конкретный шаг

Прежний NEW_PLAN сохраняется с обновлением: **шаг A — общий конвейер девяти клеток — теперь реализован**. Следующий этап:

1. Для Bminus(13,8) подтвердить полный базис свободной части/индекс найденного G и кручение. Ранг 1 сам по себе этого не доказывает.
2. Построить условия на k,T по небольшому заранее ограниченному набору хороших простых, пользуясь всеми пятью клетками, а не только произведением LU.
3. Обрабатывать полюса рациональных карт отдельными локальными ветвями; не удалять их лишь из-за нулевого знаменателя в F_p.
4. Сохранить допустимые остатки и точные групповые периоды. При непустом остатке не объявлять конечный поиск доказательством; нужен дополнительный аргумент полноты.
5. После отладки повторить для Bminus(16,5), затем B(15,8), где известные вырождения мешают простому доказательству пустоты решета.

Старый интегральный мост остаётся возможным источником p-адических условий и высот на соответствующих покрытиях. Его возвращаем в расчёт только после проверки предпосылок конкретного метода, а не вместо недостающего условия подъёма.

Запуск:

    python3 run_controls.py       # стандартный Python
    python3 map_gate_points.py    # Python с библиотекой Sage 10.9

Файлы controls.json и mapped_controls.json содержат точные результаты. Полный пакет имеет SHA256SUMS.json. Исходные записки, скрипты и процессы Claude/Grok не изменялись.
