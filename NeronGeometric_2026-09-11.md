# Néron/жёсткий локальный геометрический профиль (proxy)

Создано из `research/neron_profile/curve_reduction_profile.py`.

Сборка Sage в текущем окружении не даёт публичного API Néron для genus-2, поэтому это прокси-диагностика по `v_p(Δ)`, мод-п факторизации и кластеризации p-адических корней.

Ключевое:
- для всех пяти кривых есть стабильный набор «жёстких» плохих простых: `3,5,13,61,337,3061` и т.д.
- `3` и `5` почти везде дают кратные корни в F_p (`bad_singular_mod_p`) с `v_p(Δ)=6`.
- `2` помечено как `bad_unknown_2` (2-адическая редукция требует отдельной ветки).
- `13` почти всегда даёт один кратный линейный корень в F_p (`bad_singular_mod_p`).
- `11,61` (`v_p(Δ)>0`, без кратных корней в F_p) попадают в `bad_valuation_only` — кандидаты для более тонкого Néron-кластерного анализа.

По каждому полиному полный список: файл
`research/neron_profile/NERON_GEOMETRIC_SUMMARY_2026-09-11.md`
и JSON отчет:
`research/neron_profile/curve_reduction_profile.json`

Дальнейший шаг: добавить отдельный этап, где для `p in {11,61,...}` строить p-адические кластеры/размеры компонент явно через Magma/ PARI, когда станет доступен такой модуль.
