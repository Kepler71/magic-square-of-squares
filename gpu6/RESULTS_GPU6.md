# Сито «шести линий» на GPU (Claude, gpu6/, 2026-09-11)

Постановка — как у Codex (`research/six_lines_exact`): x = D(t₁), y = D(t₂), D(t) = 4t(1−t²)/(1+t²)², t = a/b, gcd = 1, b ≤ B,
0 < t < √2−1; нужны рациональные квадраты 1 + x + y и 1 − x − y (третий параметр не ограничен). Модульное сито на RX 7900 XTX,
затем CPU-повтор фильтра для всех выживших и точная целочисленная проверка. Статус: конечный вычислительный поиск.
