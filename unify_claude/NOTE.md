# G1 и наклоны — одна арифметика

**Тождество.** 2-изогения с ядром (0,0) переводит E_{a,b}: y² = x(x+a²)(x+b²) в
E′: Y² = X(X−(a+b)²)(X−(a−b)²). При a = m², b = n² это ровно фактор
B(m,n): Y² = X(X−(m²−n²)²)(X−(m²+n²)²) семейства G1. Статус: доказано (алгебраическое тождество);
контроль на всех 127 парах G1 — совпадение (`g1_vs_slopes.sage`).

**Следствие.** rank B(m,n) = rank E_{m²,n²}. Закрытие пары G1 «через rank B = 0» и закрытие наклона
через кривую E_{r,s} — один и тот же вопрос о ранге в одной семье (с ℤ/2×ℤ/4, где вырожденный
квадрат — точка порядка 4). Параметрам (m, n) из G1 отвечает пара (m², n²), то есть наклон с отношением квадратов.

**Критерий на G1 (разведка).** Критерий Fable «чистого ранга 0» для (m², n²): простые делители m, n,
n²−m², n²+m². На 127 парах G1:
- rank B = 0 доказан PARI у **62** пар (совпадает с 62 старыми закрытиями через B — сверка);
- критерий объявляет чистый ранг 0 у **44** пар, **все 44 — среди этих 62**, ложных нет.

**Что это даёт.**
1. Для 44 из 62 старых закрытий есть прозрачное объяснение через простые делители — частичная замена
   недостающему аудиту оснований (условно: критерий пока гипотеза).
2. Доказанный критерий закрывал бы пары G1 при **любых** m, n, а не только до 20.
3. Доказательство критерия нужно одно на обе линии.
