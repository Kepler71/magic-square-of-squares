# Поиск «крест + k квадратных углов» по решёткам Морделла–Вейля (Claude, 2026-09-11)

Идея пользователя («каждый следующий квадрат удовлетворяет условию распределения; по точкам строим фигуру; шаг даёт расстояние»)
в строгой форме: для сечения (b,h,n) угол i — квадрат ⟺ Y² = Q_i(t) — кривая рода 1 с рациональной точкой (параметр сечения);
все такие t — образы E_i(ℚ) (решётка Морделла–Вейля), шаг — прибавление генератора, «расстояние» — каноническая высота ĥ(nG) = n²ĥ(G).
Совпадение двух углов — пересечение решёток по t (кривая рода 5 на сечение).

Скрипты: `corner_search.sage` (отображения квартика ↔ Вейерштрасс по Коннеллу, проверены туда-обратно на 3 сечениях),
`one_section.sage`, `sections_500.txt`, лог `corners_500.log`.

Результат (статус: конечный поиск, не доказательство):
- 80 примитивных сечений с n ≤ 500, точки P = Σ nⱼGⱼ + T, |nⱼ| ≤ 5, все 4 угла, исключены вырожденные t (орбита сечения, 0, ±1):
  **невырожденных t с ≥ 2 квадратными углами — 0** (нет «креста + 2 углов» = 7 квадратов, тем более 8 и 9).
- Ранги кривых углов (mwrank/Simon, proof=False): 2 — 150, 3 — 140, 4 — 24, не определено — 3; **ни одной с рангом < 2** (наблюдение;
  вероятная причина — точки орбиты сечения дают ≥ 2 независимых точки; кандидат на теорему через ранг эллиптической поверхности над s).
- Ранее (16 сечений, |nⱼ| ≤ 6): тот же итог.

## Тип Бремнера (центр любой) — `bremner_type.sage`, 2026-09-11
Уточнение пользователя: центр C₀ = (b²+h²)/2 рассматривать и квадратным, и неквадратным («провалы/скачки»).
Постановка: полная пара креста (b,h), f² — клетка второй пары (f ∈ ℚ), d² = 2C₀ − f² не обязан быть квадратом.
Углы TL = (h²+f²)/2, TR = (b²+2h²−f²)/2, BL = (b²+f²)/2, BR = (2b²+h²−f²)/2, D = b²+h²−f² — квадратичны по f.
Пары условий = кривые рода 1 с точками f = ±h ({TL,BR,D}) или f = ±b ({BL,TR,D}); f — по решётке Морделла–Вейля.
Число квадратов = 3 + [C₀ □] + [D □] + #углов.
**Контроль: пример Бремнера–Саллоуса найден автоматически** — пара (31,17), C₀ = 625 = 25², f = 23/17 (единственное попадание ≥ 7).
Сведения Grok (`GROK_INFO_7_8_SQUARES.md`, первоисточники не открылись — не сверено): 8 квадратов над ℚ неизвестны; 7 — единственный пример;
приз Бойера €1000 за новый пример с 7/8/9; Chaffin: квадратный центр до 10²⁸, неквадратный до 10¹⁴.
Прогон: 1053 пары нечётных взаимно простых (b,h), b ≤ 101, |nⱼ| ≤ 5 → `bremner_101.log`.
**Итог прогона (b ≤ 101, 1053 пары, |nⱼ| ≤ 5, 6 базовых кривых на пару):** ошибок 0; центр — квадрат у 12 пар, не квадрат у 1041.
Единственное попадание с ≥ 7 различными квадратами — известный пример Бремнера–Саллоуса ((31,17), f = 23/17; квадраты TL, BL, BR,
не квадраты TR и D). **Новых 7-, 8-, 9-квадратных примеров нет.** Статус: конечный поиск по решёткам, не доказательство.

### Оговорка про «ранг» в логах (выявлено на (257,233))
В `bremner_type.sage` поле `rank` — это число генераторов, которые вернул `E.gens(proof=False)`, то есть нижняя оценка ранга.
Если mwrank нашёл не все генераторы, перебор шёл по подрешётке. Это ещё один источник неполноты, помимо ограничения |n|.
Сколько таких кривых, скажет сверка с верхней оценкой ранга (PARI `ellrank`, R); она не выполнялась.
