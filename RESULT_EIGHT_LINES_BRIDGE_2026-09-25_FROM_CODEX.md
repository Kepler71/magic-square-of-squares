# Восемь линий, девять клеток: что именно связывает распределение

## 1. Линейная закономерность действительно существует

Число линий, в которые входит каждая клетка:

```
3  2  3
2  4  2
3  2  3
```

Восемь равенств линейно зависимы: сумма трёх строк всегда равна сумме трёх столбцов. Ранг системы равен 7. Полная рациональная форма магического квадрата:

```
a−b     a+b+c   a−c
a+b−c   a       a−b+c
a+c     a−b−c   a+b
```

Магическая сумма равна 3a; центр равен a. Здесь пока записаны **значения клеток**, которые впоследствии должны оказаться квадратами корней.

Из общей формы следуют точные законы распределения:

- каждая противоположная пара суммируется в 2a;
- четыре угла суммируются в 4a, четыре середины сторон — тоже в 4a;
- сумма квадратов отклонений углов от a равна 2(b²+c²), а для середин сторон — вдвое больше;
- если C₄ и E₄ — суммы четвёртых степеней отклонений значений углов и середин сторон от a, то E₄−2C₄=24b²c².

Для корней клеток r_i, где значение клетки r_i² и центр a, получается, например,

    Σ_середины_сторон r_i⁴ − 2Σ_углы r_i⁴ + 4a² = 0.

Эти тождества полезны для проверки согласованности и выбора координат. Они следуют из исходных линейных условий, поэтому сами не являются дополнительными независимыми запретами.

Положительность всех клеток эквивалентна |b|+|c|<a. При нормировке a=1 параметры лежат внутри ограниченного ромба; рациональных точек в нём всё равно бесконечно много из-за неограниченных знаменателей.

## 2. Восемь магических линий и восемь арифметических троек — разные наборы

Для эллиптических кривых те же значения переставляются в сетку:

```
a−b−c   a−b   a−b+c
a−c      a    a+c
a+b−c   a+b   a+b+c
```

Её строки, столбцы и диагонали — арифметические прогрессии. Если произведение тройки x−d,x,x+d является квадратом, получается точка на E_d: y²=x³−d²x. Однако квадратность произведения не гарантирует квадратность каждого множителя: это более слабое условие, чем принадлежность соответствующей точки 2E_d(ℚ).

С исходной магической расстановкой совпадают четыре центральные линии. Четыре внешние различаются. Поэтому перестановка клеток сохраняет саму задачу, но может потерять условия, если после неё проверять только произведения выбранных троек.

## 3. Точная теорема: остаются два класса, и две магические линии их восстанавливают

Для произвольных девяти ненулевых рациональных значений предположим, что произведения всех восьми линий сетки — квадраты. Тогда их квадратные классы имеют вид

```
s     t     s+t
t     0     t
s+t   t     s
```

Здесь 0 означает класс квадрата, сложение классов означает перемножение чисел с точностью до квадрата. Это результат решения восьми уравнений над F₂: ранг 7, два свободных класса. Центр автоматически квадрат.

Возвращаемся к магической расстановке. Её верхняя строка и левый столбец дают произведения

    T=(a−b)(a+b+c)(a−c),
    L=(a−b)(a+b−c)(a+c).

Их классы равны s и s+t. Отсюда **точная эквивалентность**:

    все девять клеток — квадраты
    ⇔ восемь произведений арифметических троек, T и L — квадраты.

Если T и L квадраты, то s=0 и s+t=0, значит t=0. Все клетки восстановлены. В приложении есть явные рациональные формулы для девяти корней и проверка каждого показателя.

Это уточнение геометрии прежнего результата о базисе тройных произведений: теперь недостающие два условия имеют конкретный смысл исходных магических линий. Число независимых квадратных условий после нормировки центра остаётся 8; уменьшение сложности задачи этим не доказано.

## 4. Потеря условий видна уже в точном локальном примере

По модулю 37 берём a=1,b=14,c=16. Арифметическая сетка:

```
8   24   3
22   1  17
36  15  31
```

Все девять остатков ненулевые и различные. Все восемь арифметических произведений — квадратичные вычеты. Но T=14 — невычет, тогда как L=36 — вычет. Первая из двух недостающих проверок исключает эту конфигурацию.

Это локальный пример потери информации, не рациональный магический квадрат и не контрпример глобальному запрету. Точные таблицы для 25 простых до 101 подтверждают эквивалентность из §3 на ненулевом локусе. Они не доказывают глобальную полноту поиска.

При фиксированном общем невырожденном наклоне b=z,c=kz восемь арифметических произведений задают совместную кривую рода 81, а полная система корней — её неразветвлённое накрытие степени 4, рода 321. Два дополнительных корня — √T и √L. Значит недостающий шаг можно точно назвать: рациональный подъём через это конкретное накрытие. Род 81 по-прежнему велик. В этой специализации четыре центральных произведения квадратичные, остальные четыре кубические; называть все восемь факторов эллиптическими неправильно.

## 5. Новое арифметическое усиление, которое уже отсеивает кандидата

Для трёх ненулевых рациональных квадратов X₋+X₊=2X₀ при каждом простом p≡3 mod8 все три p-адические оценки равны. После удаления минимальной общей степени p иначе ровно два ненулевых квадрата должны иметь отношение −1 или 2; оба числа — невычеты при таком p.

При p≡5 mod8 два максимальных полюса допустимы только у крайних клеток; при p≡7 mod8 — только у средней и крайней. При 2 все три порядка полюсов также равны. Для этих утверждений не нужна хорошая редукция эллиптической кривой.

На сохранённых четырёх AP-тенях Claude:

- N=5211570 исключается при p=11: порядки корневых знаменателей равны 1,0,1;
- две тени N=26565 допускают только одну середину вместо трёх благодаря p=13;
- три тени после усиления всё ещё остаются. Их точные AP-равенства не выполнены; это предварительные кандидаты, не решения.

Ещё одна доказанная связь касается именно решётки ранга 2. Пусть P=mG+nH, Q=rG+sH, δ=ms−nr и D — корневой знаменатель x на целочисленной модели, D(O)=0. Тогда

    gcd(D(P),D(Q)) делит gcd(D(δG),D(δH)).

Доказательство: точки с полюсом порядка не меньше k образуют подгруппу формальной группы. Поэтому из P,Q в ней следуют sP−nQ=δG и mQ−rP=δH. Это верно при всех простых.

Для тройки ранга 2 общий полюс при p≡3 mod8 контролируется индексом Δ её решётки — НОД трёх определителей. Так получена связь между локальным распределением знаменателей и групповой независимостью точек. Универсальной оценки Δ и нужной оценки общих делителей двух эллиптических последовательностей пока нет. Возможный ранг 3 требует отдельного рассмотрения.
