## 1. Что утверждается

Для каждого наклона k = r/s из списка: **нет рационального z ≠ 0, при котором все восемь клеток
1 ± s z, 1 ± r z, 1 ± (s−r) z, 1 ± (s+r) z — квадраты.** Статус: **доказано (ПО)**.

«(ПО)» — опора на программы в следующих местах (всё остальное — точная арифметика своим кодом):

| шаг | чем | реализаций |
|---|---|---|
| ранг E_T ≤ 1 | PARI `ellrank` (верхняя граница = 1) | 2: и eclib `mwrank rank_bound = 1` — у 44 из 45 множителей (исключение: 111/445, T = [−556, −445, −334], там mwrank даёт ≤ 3; у двух других множителей этого наклона обе реализации дают 1) |
| граница индекса насыщения m ≤ √(ĥ(P₀)/λ) | λ — Sage `height_function().min` (нижняя граница ĥ на точках бесконечного порядка) | 1 |
| рациональные корни многочленов случая B | Sage `roots(QQ)` | 1 (контроль: над F_p, два простых, все решения среди корней) |
| список точек кручения | Sage `torsion_points` | точки проверены своим законом сложения; верхняя граница #Tors = НОД #E(F_p) по хорошим p < 700 совпала с числом точек у всех 45 |

Ранг ≥ 1 не опирается на ПО: ĥ(P₀) > 0 следует из своей строгой нижней оценки.

## 2. Метод (как проверялось)

S = −S (восемь клеток симметричны), поэтому если z — решение, то и −z. Для 3-клеточного T ⊂ S, T ≠ −T:
E_T: V² = f(X) = ∏_{λ∈T}(X + L/λ), L = ∏λ, z = X/L (тождество f(Lz) = L²∏(1+λz)).
Если E_T(ℚ) = ℤP₀ ⊕ Tors, то P_T(z) = nP₀ + t, P_T(−z) = n′P₀ + t′ и

|n² − n′²|·ĥ(P₀) ≤ |ĥ − h(x)|(P) + |h(x(P)) − h(z)| + |h(−z) − h(x(P′))| + |h(x) − ĥ|(P′) ≤ 2B + 2c₁ = C.

Отсюда: либо |n| ≠ |n′|, и тогда max(|n|,|n′|) ≤ M₀ = ⌊(C/ĥ₀ + 1)/2⌋ (**случай A**: перебор z(nP₀ + t),
1 ≤ n ≤ M₀, все t, плюс z(t)); либо n′ = ±n, и тогда z(P + t) = −z(P) для некоторого t ∈ Tors, t ≠ 0
(**случай B**: X(P+t)·(2αγX + αδ + βγ) + (αδ+βγ)X + 2βδ = 0 для z = (αX+β)/(γX+δ); после подстановки
формулы сложения — многочлен A + Y·B′ = 0 ⇒ A² − f·B′² = 0; нужны все его рациональные корни; тождественно
нулевого многочлена не встретилось ни разу). Каждое найденное z проверяется на все восемь клеток.

**Константа B — строго, без Silverman.** Удвоение x ↦ F(x)/G(x), F = x⁴ − b₄x² − 2b₆x − b₈,
G = 4x³ + b₂x² + 2b₄x + b₆, F, G сделаны целыми примитивными. Сертификат Безу: целые A_j, B_j степени ≤ 3 с
A_j F + B_j G = R·t^j для j = 0 и j = 7 (тождество проверяется точно). Для x = a/b несократимой:
|R|·H⁷ ≤ K·H³·max(|F(a,b)|, |G(a,b)|), K = max_j (сумма |коэф.| A_j и B_j), а НОД(F(a,b), G(a,b)) делит R ⇒
h(x(2P)) ≥ 4h(x(P)) − log K; сверху h(x(2P)) ≤ 4h(x(P)) + log L, L = max(Σ|коэф. F|, Σ|коэф. G|).
Телескоп ĥ = h(x) + Σ_k 4^{−k−1}(h(x(2^{k+1}P)) − 4h(x(2^kP))) даёт
**−log K/3 ≤ ĥ − h(x) ≤ log L/3, B := log max(K, L)/3**, в нормировке ĥ = lim 4^{−n} h(x(2ⁿP)).
Это та же схема, что у Codex (derive.py: `cert`, verify_certificate.py), переписанная заново (дважды: на Sage и
на чистом Python со своим гауссовым исключением).
Нормировка сверена: своя двусторонняя оценка ĥ(P₀) телескопом (k = 4…7 удвоений) содержит Sage `P.height()`
у всех 45 множителей; численно |ĥ − h(x)| на nP₀ + t, n ≤ 6…8, укладывается в B у всех 45.

**c₁** = log max(строчные и столбцовые суммы |M|), M — примитивная целая матрица z ↦ x выбранной модели
(минимальной или E1; берётся та, где C меньше). Строчные суммы дают h(Mu) ≤ h(u) + c₁, столбцовые (= строчные
у adj M) — обратное.

**ĥ(P₀) снизу**: ĥ(P₀) ≥ (h(x(2^k P₀)) − log K/3)/4^k, логарифмы — интервалы (RealIntervalField(256) в первом
проходе, Decimal с направленным запасом во втором).

**Образующая.** Кандидат — точка PARI ellrank, насыщенная eclib (индекс 1). Граница индекса m ≤ √(ĥ(P₀)/λ);
для каждого простого p ≤ m и каждого t ∈ Tors: P₀ + t ∉ pE(ℚ) — свидетель ℓ с P₀ + t ∉ pE(F_ℓ)
(второй проход: p = 2 точно, критерий 2-спуска «все X − e_i — квадраты»; нечётные p — редукцией, (N/p)·Q ≠ O).
Плюс PARI `ellsaturation` в первом проходе.
