## 2. Метод — что именно проверено

Модель (своя). Для T = {λ₁, λ₂, λ₃} ⊂ S = {±s, ±r, ±(s−r), ±(s+r)}, L = λ₁λ₂λ₃: y² = ∏(1 + λz) ⇔ Y² = g(X) = ∏(X + L/λ),
X = Lz, Y = Ly (тождество g(Lz) = L²∏(1+λz) проверено символьно). E_min — минимальная модель, X = u²x + r′
(тождество замены проверено в ℚ[x, y]). Итог: z = (a·x + b)/d — явная целая примитивная матрица.

**c₁ (обе стороны) — доказано.** Для мёбиусова γ с целой матрицей h(γx) ≤ h(x) + log(макс. ℓ₁-нормы строки);
z(x): c₁⁺ = log max(|a|+|b|, |d|); x(z) через присоединённую [[d, −b], [0, a]]: c₁⁻ = log max(|d|+|b|, |a|); c₁ = max.

**B — доказано (сертификат, без Sage-оценок высот).** Удвоение на E_min: x(2P) = F/G,
F = x⁴ − b₄x² − 2b₆x − b₈, G = 4x³ + b₂x² + 2b₄x + b₆, как формы степени 4 (формула проверена символьно по модулю
уравнения кривой во втором пути). Решив систему Сильвестра, получаем целые A_j, B_j степени ≤ 3 и R ≠ 0 с
A₀F + B₀G = R, A₇F + B₇G = R·t⁷ (проверено умножением над ℤ). Лемма (как у Codex, передоказана): для x = [m:n], НОД = 1,
НОД(F, G) делит R, отсюда 4h(x) − log K ≤ h(x(2P)) ≤ 4h(x) + log L, K = max(‖A_j‖₁ + ‖B_j‖₁), L = max(‖F‖₁, ‖G‖₁)
(верно и для O и 2-кручения при h(∞) = 0). Телескоп по ĥ = lim 4⁻ⁿ h(x(2ⁿP)):
−(log K)/3 ≤ ĥ(P) − h(x(P)) ≤ (log L)/3 для всех P ∈ E(ℚ). Беру B = max(log K, log L)/3 (фактически всегда log K/3;
верхняя сторона log L/3 = 7,4…16,6). Логарифмы — интервальной арифметикой MPFI (256 бит).

**Нормировка — проверено строго.** ĥ(P₀) заключён в вилку [(h(x(2⁷P₀)) − log K/3)/4⁷, (h(x(2⁷P₀)) + log L/3)/4⁷]
(только итерации x ↦ F/G в точной арифметике); ширина ≈ 0,003. Значение Sage P₀.height() лежит в вилке на всех 173 кривых
и на 37a1, 389a1 (обе образующие), 5077a1 (три образующие) при k = 4 и k = 8 (`norm_ctrl.log`). Значит, нормировка Sage
совпадает с ĥ_x = lim 4⁻ⁿ h(x(2ⁿP)), а в M₀ идёт нижний конец вилки, а не число Sage.

**Теорема 7.1 Fable** (перечитана и передоказана): z — решение ⇒ −z — решение (S = −S), P = P_T(z) = nP₀ + t,
P′ = P_T(−z) = n′P₀ + t′ на одной E_T; h(z) = h(−z); |n² − n′²|·ĥ(P₀) ≤ 2B + 2c₁ = C.
Случай A: n² ≠ n′² ⇒ max(|n|, |n′|) ≤ (C/ĥ(P₀) + 1)/2, M₀ = ⌊этого⌋ (интервально, верхний конец).
Перебор n = 0…M_run, все t ∈ Tors (n < 0 даёт те же z, потому что z(−Q) = z(Q)). Случай B: n′ = ±n ⇒ z(P + t) = −z(P), t ∈ Tors;
при t = O это z = 0; при t ≠ O на E1 (a₁ = a₃ = 0) условие X(P+t) + X(P) = 0 ⇔ (Y − Y_t)² = (a₂ + X_t)(X − X_t)², т. е.
A(X) = 2Y_t·Y с A = g + Y_t² − (a₂+X_t)(X−X_t)² ⇒ корни A (при Y_t = 0) или A² − 4Y_t²g (многочлен ненулевой — старший член).
Для каждого рационального корня проверяются z = X/L и −z на все 8 клеток.
