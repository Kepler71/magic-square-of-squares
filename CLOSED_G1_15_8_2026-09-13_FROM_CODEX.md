## Точное утверждение

Пусть t∈Q и

```
F0=225+64t², F4=(289/2)(1+t²), F8=64+225t²,
L=F4−240t, U=F4+240t.
```

**Все пять чисел являются рациональными квадратами тогда и только тогда, когда t=1 или t=−1.** Значение t=∞ в однородной модели исключается: ведущий коэффициент F4 равен289/2 и не является рациональным квадратом.

При t=1 полный квадрат равен

```
289 529 49
49 289 529
529 49 289
```

При t=−1 клетки переставляются. В обоих случаях различных значений три. Следовательно, **в G1-паре (15,8) нет полного магического квадрата из девяти различных рациональных квадратов**, при любом рациональном t и квадратном масштабе.

Статус: воспроизводимое вычислительное доказательство на основе указанных теорем и CAS. Это завершает прежний открытый случай (15,8). С учётом ранее принятых126 исключений закрыт фиксированный список127 G1-пар m>n>0, gcd(m,n)=1, m≤20. Остальные126 в этом запуске заново не вычислялись; общая задача за пределами списка не решена. Пустота C7(Q) или определение всего D(Q) не утверждаются.

## Цепочка доказательства

### 1. Сведение и все карты

При t=(1+x)/(1−x) умножаем исходные клетки на квадрат (1−x)². Получаем пять форм

```
289(1+x²)−322x, 289(1+x²), 289(1+x²)+322x,
49+529x², 529+49x².
```

Произведение первой, третьей и четвёртой даёт

```
D: y²=44182609x⁶+37608911x⁴+47287151x²+4092529.
```

Тождества проверены в Q(x), гладкость — через gcd(f,f′)=1. Каждый рациональный пятиформный подъём даёт точку D(Q). x=0 соответствует t=1, x=∞ соответствует t=−1, x=1 соответствует уже исключённому t=∞. Вне этих карт обращение преобразования явно задано.

При11 из всех12 проективных параметров x только0 и∞ допускают пять квадратностей. На D это четыре диска: y=±2023 около0, y/x³=±6647 около∞. Нули по модулю11 разрешены. Этот полный конечный перебор воспроизведён заново.

### 2. Эллиптические факторы и базисы

Для (a0,a2,a4,a6)=(4092529,47287151,37608911,44182609):

```
phi1=(a6x²,a6y), phi2=(a0/x²,a0y/x³).
E1: Y²=X³+a4X²+a2a6X+a0a6²,
E2: Y²=X³+a2X²+a4a0X+a6a0².
```

Оба ранга1 заново подтверждены PARI и eclib. eclib.saturate(bound=−1) выполнен без искусственного ограничения по простым; получены те же базисы с точностью до знака и кручения:

```
P1=(21848689,286391046720), T1=(−4092529,0),
P2=(−18241391,87162492480), T2=(−44182609,0).
```

Порядок рационального кручения2 дополнительно подтверждён НОД количеств точек при хороших простых11,19,29 и предъявленными точками T_i. Отношения дискриминантов исходных и минимальных моделей равны1. Обе кривые имеют хорошую обыкновенную редукцию при11; порядки E_i(F11) равны14 и10. Согласованы исходные модели, минимальные модели и переносы координат. Результаты находятся в core_chain.json.

### 3. Полное надмножество высот

OMEGA_ALL_VALUATIONS.md содержит отдельный разбор всех k=v_q(x), включая неограниченные хвосты и возможные отмены при k=±2. Для шести плохих простых3,5,13,37,1213,9397 гладкость допустимых интегральных образов проверена полным перебором, а случаи k≠0 рассмотрены по оценкам. При2 допустимые образы дают нулевой вклад. При7,17,23 получаем

```
Omega_full={c7 log11(7)+c17 log11(17)+c23 log11(23):
            c7∈{−2,−4/3}, c17∈{−2,0,2}, c23∈{2,4/3}}.
```

Случаи x=0,∞ включены посредством непрерывного продолжения. Их значения дополнительно проверены точными локальными высотами точек −2P1 и −2P2. Это надмножество только для пятиформного локуса, не для всех D(Q).

### 4. QC-функции заново, другим алгоритмом

direct_sigma.py не импортирует и не загружает qc_g2_mixed_full_lift.sage. Вместо прежнего вычисления через двойные интегралы используются закон изменения локальной высоты при умножении, p-адическая сигма-функция и полином деления. Логарифмические особенности около0 и∞ удаляются явно и сокращаются с членом −2log(x). Глобальные коэффициенты alpha_i=h(P_i)/Log(P_i)² получены заново на минимальных моделях.

Sage по-прежнему предоставляет сигма-функции, глобальные p-адические высоты и полиномы деления. Это другая реализация построения QC-функций, но не другой CAS и не внешняя проверка всей теории. В коде отмечены входы и пределы независимости.

Первые16 коэффициентов обеих функций вычислены с абсолютной точностью не меньше39. После завершения нового построения выполнено сравнение со старым файлом: коэффициенты совпали минимум до11²⁹. Совпадение используется как дополнительный контроль, а новое покрытие строится из новых коэффициентов.

### 5. Хвосты и исчерпывающая изоляция корней

Теоретические входы: теорема2.3 связывает рациональные точки с высотами; Proposition3.12, Lemma3.13 и Proposition3.14 дают оценки коэффициентов, хвостов и двойные нули в известных точках. Условия проверены для нашей модели. [Bianchi–Padurariu](https://arxiv.org/html/2212.11635v1).

Здесь epsilon=−1, M=16. Для ряда в масштабированном параметре u=11z оценка пропущенного хвоста равна

```
N=M−floor(log11(M))−floor(log11(M−1))+epsilon=13.
```

По новым коэффициентам cover_roots.py проверяет все24 уравнения (две ветви ×12 высот). После необходимых уточнений диска каждый случай либо не имеет корней, либо имеет простые корни по Гензелю, либо содержит известный двойной нуль, исчерпывающий границу Штрассмана2. Двойные нули обоснованы точным значением высоты известной рациональной точки и симметрией; округлённый нуль не принимается за тождественный.

Результат: четыре известные точки и **ровно40 попарно различных окрестностей по модулю11⁵**. Они совпали с прежним списком на этой точности. Более тонкие старые цифры для полноты не нужны. root_coverage.json содержит все24 разбора и40 окрестностей.

### 6. Из новых окрестностей прямо в решето

ball_dlog.py получает только эти окрестности modulo11⁵. Внутри каждой выбирается произвольный точный параметр и его согласованный квадратный корень. Эта точка не выдаётся за QC-корень на повышенной точности. Коэффициенты MW modulo11² постоянны на всей окрестности: поднятые дифференциалы интегральны в выбранных картах; Log(P_i) имеет оценку1, поэтому точности окрестности достаточно с запасом.

Полученные классы проверены при83,191,751. Все независимые комбинации кручения разрешены; условие чётности из образа якобиана не требуется.

| Простой | Исключено новых окрестностей |
|---|---:|
| 83 | 20 |
| 191 | 16 |

Конечные множества ранее вычислены стандартным Python и отдельно средствами Sage; они совпадают. Все четыре известные точки проходят фильтры. finish_chain.py связывает новые окрестности, новые коэффициенты MW и эти проверенные конечные множества. Результат: ни одна из40 окрестностей не содержит рационального полного подъёма.

## Итог и предел результата

Для выбранной пары осталось ровно t=±1. Это доказательство не ограничивает высоту t или размер целых корней. Результат относится к полной девятиклеточной задаче внутри G1(15,8), а не к пустоте C7 и не ко всем рациональным точкам D.

Сертификат использует стандартную теорию и CAS. Внешнего человеческого рецензирования нет; слово «независимый» не означает, что были независимо заново доказаны теоремы высот, алгоритмы Sage или весь eclib. Для публикации полезен внешний сквозной просмотр, но прежний конкретный пробел «не доказана полнота списка40» в этой цепочке устранён.
