## §1 и §5 символьно (`symbolic_check.sage`)
- E⁺ → E(a, b), M − N = (b − a)(a + b)³ — тождества верны.
- A(v) = λ⁴(M + N), B(v) = λ⁸MN при v = (2a − b)/(2a + b), λ = 4/(2a + b) — верно.
- Точка серии лежит на E(a(w), b(w)); совпадения x с семью абсциссами кручения только при w ∈ {0, ±2} — вне 0 < w² < 2.
- При w = 1: (a, b) = (7, 2), точка бесконечного порядка, кручение Z/2×Z/6, все абсциссы кручения из списка Codex.
- k_n = (4n² − 2)/(8n² − 1) = b/a при w = 1/n, n = 1..5 — верно.

Серия — ограничение одного фильтра, а не утверждение о квадрате. — доказано (символьно + Мазур).
