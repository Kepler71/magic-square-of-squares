## 1. У вещественного интеграла могут быть изолированные нули

Утверждение Claude «над R нули не изолированы, их континуум», поддержанное Grok, неверно. Для нетождественно нулевой вещественно-аналитической функции одной переменной нули изолированы внутри области аналитичности. Пример из нашей текущей квартики:

```
F(p)=integral_0^p du/sqrt((1−(40u/43)^2)(1−(83u/43)^2)),
|p|<43/83.
```

Подынтегральная функция положительна и аналитична, поэтому F строго возрастает и имеет ровно один нуль, p=0. Это точное доказательство; численное демо на полчаса не требуется. Этот пример опровергает общее утверждение, но не является вычислением конкретного интеграла на сечении (71:49:61).

Подлинная трудность — построить функцию, нули которой обязаны содержать все рациональные точки. В классическом Шаботи–Коулмане выбирают дифференциал, аннулирующий логарифмы группы Морделла–Вейля; условие rank J(Q)<g обеспечивает ненулевой выбор. Произвольный интеграл dp/Y такого свойства не получает. При rank=g классический критерий не срабатывает автоматически, нужны дополнительные условия/квадратичный метод. [Обзор Jennifer Balakrishnan, Chabauty and Beyond](https://doi.org/10.1137/25m1805011).

Поэтому «перевод сечения в интеграл — ТОЧНО Шаботи» тоже слишком сильная формулировка. Наша цепочка dp/Y → эллиптическая модель → спуск → все точки кручения работает без построения аннулирующего интеграла Шаботи. Вещественные оценки и интегралы не запрещены; сами по себе они не дают арифметического критерия рациональности.

## 2. Угловая параметризация не уничтожает арифметику

При z=tan(theta/2) имеем

```
C=(1−z²)/(1+z²), S=2z/(1+z²), C²+S²=1,
r=C+S, s=C−S, r²+s²=2.
```

При рациональном z получаем рациональные r,s. Квадратность клеток выражается рациональными уравнениями с дополнительными корнями. Исключённая точка карты z=∞ учитывается отдельно. Нельзя произвольно вращать уже найденные значения клеток и ожидать сохранения квадратности, но утверждение «через углы вопрос не выражается вовсе» неверно. Эти два тезиса различны. Тождества перепроверены символически.

## 3. Поправка Grok про 2048 подтверждена

В Theorem 1 Auel–Singer указано Aut(V_Qbar)=Aut(Vtilde_Qbar) порядка 2048: восемь симметрий расположения клеток и 256 проективно различных смен знаков корней. Знаки тривиально действуют на квадраты клеток. Поэтому перебор перестановок клеток не вычисляет всю группу поверхности корней. Непрерывной группы алгебраических автоморфизмов этой поверхности нет. Это не запрещает локальные аналитические координаты, движение по вещественным ветвям или алгебраические соответствия, не являющиеся автоморфизмами. [Auel–Singer, Theorem 1 и §1.2](https://arxiv.org/html/2609.09351v1).

## 6. Новый точный мост к нашей границе знаменателя 48

Из матрицы G1

```
F0       (mt+n)²  L
(mt−n)²  F4       (m+nt)²
U        (m−nt)²  F8
```

после деления на F4 получаем нашу матрицу M(p,q), где

```
p=(m²−n²)(1−t²)/((m²+n²)(1+t²)),
q=−4mnt/((m²+n²)(1+t²)).
```

Все девять тождеств проверены в Q(m,n,t). Квадратность после нормировки сохраняется при условии, что F4 — ненулевой рациональный квадрат. Алгебраические тождества верны и без этого условия.

После D8-нормировки k=min(|p|,|q|)/max(|p|,|q|). Для (15,8):

```
p=161(1−t²)/(289(1+t²)), q=−480t/(289(1+t²)).
```

Для t=a/b в несократимом виде положим A=161|b²−a²|, B=480|ab|. Если A,B ненулевые и не равны, знаменатель k равен max(A,B)/gcd(A,B). Случаи A=0, B=0 или A=B дают повторения клеток.

Проверено, какие из всех 711 наклонов до знаменателя48 вообще достигаются при рациональном t. Для 0<t<1 и r=|q/p| нужны

```
161r t²+480t−161r=0,
240²+(161r)² ∈ Q²,
r=k либо 1/k.
```

Результат полный, с точностью до t→−t и t→1/t:

| k | Представитель t | F0 квадрат? |
|---|---|---|
| 10/23 | 1/7 | нет |
| 7/34 | 17/23 | нет |
| 23/34 | 7/17 | нет |
| 23/36 | 3/7 | нет |
| 44/45 | 23/77 | нет |

Также F8 не квадратен во всех пяти случаях, поэтому инверсия t не возвращает допустимые точки. Остальные наклоны вообще не имеют рационального прообраза в этой G1-паре. Следовательно, **на (15,8) новая граница 48 не усиливает уже имеющееся условие трёх квадратностей**. Это точная проверка полезности нашей новой линии для старого остатка. Граница остаётся верной для общего нормированного квадрата; историческая новизна не установлена.
