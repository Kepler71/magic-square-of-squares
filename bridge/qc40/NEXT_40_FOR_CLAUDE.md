# Следующая задача Claude: сорок дополнительных 11-адических кандидатов

Новые теоретические результаты и завершённый пилот находятся в MIXED_GENUS2_BRIDGE_2026-09-12.md, TWELVE_HEIGHT_VALUES.md. Не запускать стандартное Ω на59млн: доказанное надмножество для полного подъёма содержит12 значений. Независимый Spark после дополнения проверил логику всех оценок k, явных ошибок не нашёл (SPARK_INDEPENDENT_HEIGHT_REVIEW.md).

1. Взять qc_mixed_15_8_p11_n30_twelve_check.json и соответствующие functions.json; сохранить принадлежность каждого кандидата к конкретному Ω (порядок: c7=-2,-4/3; затем c17=-2,0,2; затем c23=2,4/3). Не смешивать их до построения решета.
2. Вычислить полный базис E1(Q),E2(Q) и его насыщенность. Модели, ранги1 и точки есть в new_bridge_verified.json. Для логарифмического отношения одной неторсионной точки достаточно, для полного решета нужен проверенный индекс подгруппы.
3. Использовать карты φ1=(a6 x²,a6 y), φ2=(a0/x²,a0 y/x³) и условия согласования образа Jac(D) под (2,2)-изогенией. Даже если начать с надмножества E1(Q)×E2(Q), нельзя делать исключения, основанные на необоснованном равенстве этого произведения всему образу Jac(D)(Q).
4. Экспортировать локальные классы новых кандидатов в MW-решето по §4.2 Bianchi–Padurariu. Работать с обоими факторами совместно. Для каждого удалённого кандидата сохранять конечный сертификат несовместности. Если кандидат не удаляется, это не рациональная точка без отдельного доказательства.
5. Любые распознанные рациональные x поднимать через t=(1+x)/(1-x), проверяя F0,F4,F8,L,U по отдельности и все девять клеток. x=1 и x=∞ обрабатывать отдельно.

Контроль: четыре известные точки D дают t=±1; они должны сохраняться. Статус остаётся126/127 для невырожденной девятки. Комплект не утверждает D(Q)={четыре точки}; профиль QC охватывает только образ полной системы. Старое B с k≡0mod840 не подменяет новые координаты группы.

Изоляция нулей при этих оценках отдельно проверена в strassmann_audit.json. Для литературной новизны отдельный поиск не завершён; считать это новым результатом нашего проекта.
