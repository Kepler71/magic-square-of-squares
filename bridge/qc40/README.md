# Смешанный фактор G1(15,8): новый глобальный путь

Основная записка: MIXED_GENUS2_BRIDGE_2026-09-12.md.
Главное новое доказательство: TWELVE_HEIGHT_VALUES.md.
Сначала читать эти два файла. Итог пока НЕ 127/127: остаются40 дополнительных11-адических кандидатов.

Стандартный Python:

    python3 local_discs_11.py
    python3 unramified_height_primes.py
    python3 check_height_coefficients.py

Sage10.9 через системный Python с sage.all:

    python3 verify_new_bridge.py
    python3 verify_zero_height_primes.py
    python3 audit_qc_precision.py
    python3 audit_strassmann.py

Новый короткий расчёт (выполнять в каталоге пакета):

    python3 run_qc_twelve.py mixed_15_8 11 30 repeat

Он использует только12 доказанных допустимых значений высоты и две орбиты допустимых дисков. Исходный run_qc.py даёт огромную общую оценку; для нашей цели повторять его не нужно. Два остановленных пилота сохранены с явным статусом неполноты. Завершённые расчёты: qc_mixed_15_8_p11_n20_twelve.json и qc_mixed_15_8_p11_n30_twelve_check.json.

Статусы: тождества и оценки высот обоснованы алгебраически; ранги сертифицированы PARI/eclib; реализация QC опубликована Bianchi–Padurariu и адаптирована к Sage10.9. Изоляция нулей проверена отдельно при условии корректности сохранённых оценок остатков и интегралов библиотеки. Все40 точек ещё не исключены глобально. Совпадение двух точностей само по себе не считается полным доказательством рациональности или её отсутствия.

Новые модели E1/E2 не совпадают со старым B, на котором k≡0mod840. Для переноса ограничений нужны карты и условия подъёма. Полные базисы для нового MW-решета и индекс образа изогении ещё проверить.

Источник QC: https://github.com/bianchifrancesca/QC_bielliptic . Сохранены исходник, совместимая версия и патч. Теория: https://arxiv.org/html/2212.11635v1 .
