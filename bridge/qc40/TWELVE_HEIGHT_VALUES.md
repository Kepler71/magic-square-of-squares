# Сокращение множества высот до 12 значений

Область: только образ полной системы пяти квадратностей G1(15,8) на смешанной D. Это НЕ оценка для всех D(Q).

Пишем w_q=-λ_q(φ1(P))+λ_q(φ2(P))−2v_q(x)log(q). Обе модели Ei уже минимальны: отношения дискриминантов с минимальными моделями равны 1, изоморфизмы — целые переносы X. Поэтому нормировки высот библиотеки совпадают с нормировкой ниже.

## Шесть простых с нулевым вкладом

Для q=3,5,13,37,1213,9397 коэффициенты a0,a6 — единицы. На интегральных единичных x обе φi(P) интегральны. Сингулярный образ возможен лишь при y=0 modq и одновременно нулевой производной кубика Ei по X. Перебор всех x∈Fq, допускающих пять квадратностей (нули разрешены), показывает отсутствие такого образа. Это полный конечный сертификат, а не выборка: unramified_height_primes.py/json.

Если v_q(x)>0, φ1(P) редуцируется в гладкую точку над X=0 (Y — единица), а X(φ2(P)) имеет оценку −2v_q(x). Поэтому λ1=0, λ2=2v_q(x)logq. Если v_q(x)<0, роли меняются: λ1=−2v_q(x)logq, λ2=0. В обоих случаях w_q=0. При v_q(x)=0 гладкость даёт λ1=λ2=0. Значит, w_q=0 на всём допустимом локальном образе, включая особые карты по непрерывному продолжению.

## Простое 2

v2(x)=0 невозможно: 289(1+x²) имеет нечётную оценку 1. При v2(x)>0 образ на E1 интегрален и производная кубика по X нечётна (a2*a6 нечётно), а образ на E2 лежит у бесконечности. Получаем λ1=0, λ2=2v2(x)log2. При отрицательной оценке симметрично λ1=−2v2(x)log2, λ2=0. Итак, w2=0.

## Простые 7,17,23: полный разбор по k=v_q(x)

В таблице r_i=λ_q(φ_i(P))/logq. Все модели мультипликативные; v_q(c4)=0. При сингулярном интегральном образе используем формулу r_i=−b(N−b)/N, b=min(v_q(2Y),N/2), N=v_q(Δ). При гладкой редукции r_i=0, при отрицательной оценке X имеем r_i=−v_q(X).

|---|---|---|---|---|
| 7 | k<0 | −2k | −4/3 | −4/3 |
| 7 | k=0 | 0 | −4/3 | −4/3 |
| 7 | k≥1 | 0 | 2k−2 | −2 |
| 23 | k≤−1 | −2k−2 | 0 | 2 |
| 23 | k=0 | −4/3 | 0 | 4/3 |
| 23 | k>0 | −4/3 | 2k | 4/3 |

| 17 | k≥2 | −2 | 2k−4 | −2 |

Обоснование полноты случаев:

- При 7 дискриминантные оценки Ei равны 2 и 6. По модулю 7 f(x)=2x²(x²+1)²; −1 не квадрат. При k≤0 это определяет оценку y без отмены ведущих членов. Для k≥1 E1 гладка над X=0; на E2 при k=1 X — единица и не сингулярная точка, при k>1 X имеет отрицательную оценку. Это даёт первые три строки, даже если в f(x) при k=1 есть дополнительная отмена.
- При 23 дискриминантные оценки равны 6 и 2; обратная карта x↦1/x меняет роли. По модулю 23 f(x)=a0(1+x²)², −1 не квадрат. Получаем следующие три строки.
- При 17 обе оценки дискриминантов равны 8; v17(a0)=v17(a6)=4, а a2,a4 — единицы. k=±1 невозможны: хотя бы форма 289(1+x²)−322x имеет нечётную оценку. При k=0 обе точки имеют X,Y, кратные 17; v17(Y_i)≥4, поэтому b=4 и r1=r2=−2. При k≥2 первая точка имеет b=4, а вторая при k=2 имеет единичный X (гладкая редукция), при k>2 отрицательную оценку X. При k≤−2 роли меняются. Отмена членов f при k=±2 не меняет гладкости единичного X и не меняет b=4 другого фактора.

x=0 и обе бесконечности включаются по непрерывному продолжению комбинации w_q. Значения известной точки x=0: (w7,w17,w23)=(-2log7,-2log17,(4/3)log23); на бесконечности: (-(4/3)log7,2log17,2log23).

Отдельный точный вычислительный контроль таблицы: check_height_coefficients.py перебирает v_q(x) от −4 до4 и все единицы u от1 доq², оставляет лишь локальную квадратность пяти форм, вычисляет локальные высоты по формулам минимальной модели. Проверено 12+294+1159+3726 локальных примеров. Это проверка вывода, а не замена приведённого разбора всех целых k.

## Итоговая строгая верхняя оценка

На всех остальных хороших простых вклад нулевой. Список плохих простых и нормировки проверены в omega_structure.json и zero_height_model_checks.json. Для образа любого полного рационального квадрата:

    ρ̃(P) ∈ Ω_full ⊂
    {c7 log11(7)+c17 log11(17)+c23 log11(23):
     c7∈{−2,−4/3}, c17∈{−2,0,2}, c23∈{2,4/3}}.

Таким образом, достаточно не более 12 значений вместо стандартной верхней оценки 59 506 083. Совместность всех 12 троек не утверждается; надмножества достаточно для доказательного отсечения. Все утверждения требуют наличия пяти локальных квадратностей, поэтому библиотечный запуск с этим Ω не определяет всё D(Q).

Ссылка на нормировку λ и теорему высот: Bianchi–Padurariu, Theorem 2.3, https://arxiv.org/html/2212.11635v1 . Формулы местной высоты также видны в сохранённой функции non_archimedean_local_height; самостоятельная проверка изложена выше.

## Дополнение после независимого замечания Spark: явные оценки y для всех k

Это закрывает переход от конечных тестов к любым целым k. Пусть l=v_q(y), где y²=f(x). Все оценки ниже следуют из сравнения членов f; они относятся к локальной точке D, допускающей пять квадратностей.

- q=7: l=3k при k<0; l=0 при k=0; l=1 при k>0. Для k=1 возможная на первый взгляд отмена в 49+529x² сводится к u²=−1/529 mod7 при x=7u и невозможна, поскольку −1 не квадрат. Для k>1 постоянный член этого фактора строго доминирует. Вторая скобка при k>0 — единица. Для k<0 старший член f строго доминирует. При k=0 используем f mod7=2x²(x²+1)², не обращающееся в нуль на единицах.
- q=23: l=1+3k при k<0; l=0 при k≥0. При k=−1 возможная отмена в 49+529x² требует u²=−49 mod23 и невозможна; при k<−1 старший член первого фактора строго доминирует. Второй фактор при отрицательных k имеет оценку 4k. При k≥0 f mod23=a0(1+x²)² — единица. Это прямой расчёт для нашей модели, не предположение об автоморфизме x↦1/x.
- q=17: при k≥3 имеем l=2; при k=2 имеем l≥2; при k=0 имеем l≥0; при k=−2 имеем l≥−4; при k≤−3 имеем l=2+3k. Отмены при k=±2 разрешены, и приведённые нижние границы достаточны. При k=1 форма 289(1+x²)−322x имеет оценку min(2,1)=1; при k=−1 — min(0,−1)=−1. Оба значения нечётны, так что эти два случая запрещены без перебора.
- q=2: для k>0 l=0, для k<0 l=3k. При k=0 центр имеет оценку1. Более того, k=1 невозможен, поскольку единица 1+x²≡5 mod8; для k=−1 применяем ту же проверку после умножения на x^(-2), являющееся квадратным масштабом. Значит фактически |k|≥2; доказательство w2=0 работает для всех k≠0 и потому не нуждается в этом усилении.

Оценки координат факторов выражаются без каких-либо скрытых случаев:

    v(X1)=v(a6)+2k, v(Y1)=v(a6)+l,
    v(X2)=v(a0)−2k, v(Y2)=v(a0)+l−3k.

При q=7 значения (v(a0),v(a6))=(2,0); при q=23 — (0,2); при q=17 — (4,4); при2 — (0,0). Подставляя эти четыре пары и явные оценки l в формулу местной высоты, получаем всю таблицу выше для неограниченного k. В случаях единичного X и возможного нулевого Y редукция кубика при q=7,23,17 имеет единственную двойную точку при X=0, если этот случай используется в таблице; остальные корни просты. В частности, отмены при k=±2 для17 не порождают нового значения высоты.

При7 для E1 и k>0 редукция над X=0 гладкая, поскольку коэффициент при X — единица. При23 для E2 и k<0 работает тот же аргумент. При2 нужная производная нечётна. Все другие используемые сингулярные случаи имеют положительные оценки X,Y на редукции X²(X+c), c — единица; приведённая мультипликативная формула применима.

Продолжение на x=0,∞ не выводится из выборки: во всех достаточно глубоких проколотых локальных окрестностях w_q уже константа по таблице. Комбинация высот имеет непрерывное продолжение по Theorem 2.3, поэтому значение на центре обязано равняться этой константе.
