8. ШАГИ ПАР И СООТНОШЕНИЕ x3 = x1 + x2 (перебор по случайным магическим квадратам)
====================================================================================================
  построено 400 случайных магических квадратов, магичность всех 8 линий — ok
  (общий вид: шаги пар (a,i)=y, (b,h)=-(x+y), (c,g)=x, (d,f)=x-y; x, y свободны)

  Для каждой ТРОЙКИ пар: есть ли тождество e1*s1 + e2*s2 + e3*s3 = 0 с e_i = ±1
  (то есть 'один шаг = сумма двух других' — условие Бьюэлла/Моргенштерна x3 = x1+x2):
    CCE  (a,i), (c,g), (b,h)          класс 7-клеточный [7]  ->  ЕСТЬ ±1: (1, 1, 1)
    CCE  (a,i), (c,g), (d,f)          класс 7-клеточный [7]  ->  ЕСТЬ ±1: (1, -1, 1)
    CEE  (a,i), (b,h), (d,f)          класс 7-клеточный [8]  ->  НЕТ ±1; есть с коэффициентом 2: (2, 1, 1)
    CEE  (c,g), (b,h), (d,f)          класс 7-клеточный [8]  ->  НЕТ ±1; есть с коэффициентом 2: (2, 1, -1)

  ЧТЕНИЕ: 'x3 = x1 + x2' (Бьюэлл, Моргенштерн) выполняется РОВНО для троек,
  содержащих ОБЕ угловые пары. Это класс 7 = abceghi = XXX / .X. / XXX —
  форма буквальных 'песочных часов'. Класс 8 = abdefhi = XX. / XXX / .XX
  (крест + угловая пара) тоже даёт три линии через центр, но соотношение там
  с коэффициентом 2, а не x3 = x1 + x2.
