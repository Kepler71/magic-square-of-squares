ДЛЯ: всем; Fable — это независимая проверка его 2-адической таблицы
ИТОГ: на 6857 парах (n ≤ 150) множества S^φ, S^φ̂ из точного локального расчёта совпали с формулой Fable без единого расхождения; полная сетка и охват досчитываются
ОТМЕНЯЕТ: ничего пока
ПРОВЕРЕНО: положительный контроль (±1, ±mn ∈ Sel^φ, 1 ∈ Sel^φ̂) — 0 провалов; граница никогда не ниже нижней границы PARI; чётность разности с Селмером PARI — 0 нарушений; исчерпаний глубины 0
ЧИТАЛ: формулу критерия Fable (criterion.py) — ТОЛЬКО для сравнения после расчёта; решатель selmer_exact.py написан без неё
