Магический квадрат 3×3 из квадратов · рабочая записка

Сечения s = 1/5 и 1/4

Два сечения семейства «центрального креста» не содержат магического квадрата из девяти различных рациональных квадратов. Ниже — постановка, общая схема доказательства, данные по каждому сечению и полный перечень зависимостей.

11 сентября 2026Claude Code · Codex · Grokне рецензировано

Что утверждается

Утверждение. Пусть центральный крест квадрата с центром 1 содержит пару клеток B(s)², H(s)² при s = 1/5 (эквивалентно 2/3, 5, 3/2) или при s = 1/4 (эквивалентно 3/5, 4, 5/3). Тогда все девять клеток любого такого магического квадрата из рациональных квадратов принимают не более трёх различных значений.

доказано (ПО) Доказательство опирается на вычисления Sage/PARI/mwrank, одну верхнюю границу ранга из Magma на сечение и собственную реализацию эллиптического Шаботи; все звенья перечислены в разделе «Зависимости».

Общая задача Гарднера этим не решается: сечений бесконечно много, закрыты два. Для шести из одиннадцати проверенных сечений этот метод, по-видимому, неприменим (ранг ≥ 2).

Постановка

Нормируем центр до 1. Пары противоположных клеток креста лежат на окружности B² + H² = 2 с параметризацией

B(u) = (1 + 2u − u²)/(1 + u²), H(u) = (1 − 2u − u²)/(1 + u²).

Крест задают параметры s и t: b = B(s), h = H(s), d = B(t), f = H(t). Магичность вынуждает углы a² = (h² + f²)/2, c² = (h² + d²)/2, g² = (b² + f²)/2, i² = (b² + d²)/2. Сечение — фиксированная пара b = β/n, h = η/n с β² + η² = 2n² (здесь β, η — числители); положим

A = (η² + n²)/2, C = (β² + n²)/2, A + C = 2n².

Условие «четыре угла — квадраты» задаёт кривую Cs рода 49 над прямой t:

Y₁,₂² = A(t²+1)² ± 2n²·t(t²−1), Y₃,₄² = C(t²+1)² ± 2n²·t(t²−1).

Для s = 1/5: (β, η, n) = (17, 7, 13), A = 109, C = 229. Для s = 1/4: (23, 7, 17), A = 169, C = 409. На каждом сечении есть «вырожденные» точки — t из орбиты самого s; справа такой квадрат для s = t = 1/5, умноженный на 169: встречаются только 7², 13², 17².

Общая схема для сечения

Шаги 1–4 выведены для произвольных A, C; отличаются только числовые данные.

  1. Отображение на кривую рода 2

    X = (Y₃ − Y₄)/(Y₁ − Y₂) лежит одновременно на Q: (A X² − C)(X⁴ − 1) = □ и Q′: (C X² − A)(X⁴ − 1) = □. Исключение Y-координат даёт тождество

    [2n²·t(t²−1)(1−X⁴) / (2X(t²+1)²)]² = (C − A X²)(A − C X²).

    доказано символически; исключительные случаи t = 0, ±1, ∞, w = 0, X = ±1 разобраны для каждого сечения.

  2. Классы спуска

    Для X = p/q классы (d₁, d₂, d₃) — свободные от квадратов части p² − q², p² + q², A p² − C q²; дополненная система добавляет C p² − A q² = d₃ v². Кандидаты берутся из делителей попарных результантов; каждый либо содержит известную точку, либо не имеет точек над ℝ или ℚℓ (строгий тест дроблением ℤℓ на шары).

    доказано (ПО) В обоих сечениях локально разрешимы ровно 4 класса.

  3. Бисэллиптичность и ранг

    Фактор CJ₂: d₃W² = t(t²−1)(At − C)(Ct − A). Замена z = (t−1)/(t+1) даёт y² = c·z(z²−1)(z² − β′²), β′ = (C − A)/(C + A) ∈ ℚ, поэтому инволюция z ↦ β′/z поднимается над k = ℚ(√((C−A)(C+A))) и Jac(CJ₂) ~ Resk/ℚ E₁. Верхняя граница ранга — по двойственной Ришело-модели, для которой при разбиении {0,∞},{1,−1},{C/A, A/C} доказано тождество

    δ·G₁G₂G₃ = (2ACD)²·D(t²−1)(t²+1)(½(A²+C²)t² − 2AC·t + ½(A²+C²)).

    доказано тождества; ПО границы Magma RankBounds.

  4. Эллиптический Шаботи и обратный переход

    При rank E₁(k) = 1 точки P = T + rG + m·NG с x(P) ∈ ℚ — нули p-адического ряда θ(m) = σ₁x − σ₂x по двум вложениям k → ℚp. Классы вычетов отсекаются по модулю p; в остальных число нулей ограничено по Штрассману со строгой оценкой хвоста vp(cₙ) ≥ n − vp(n!); подгруппа ⟨G⟩ насыщена локально по всем ℓ | pL. Нули либо целые (известные точки), либо в точности m = −1/2 (образы тех же точек через 2-кручение).

    доказано (ПО) Итог: x-рациональны только O, T₁, T₃, ±G₀; их прообразы — вырожденные X.

Зависимости

Что именно должно быть верно, чтобы утверждение держалось, и чем это подкреплено.

  • Ручные выводы: тождество (шаг 1), критерий подъёма через 1 ± 4h, бисэллиптичность над k, связь ранга J₂ и E₁(k). Каждый вывод продублирован символической или численной проверкой (совпадение многочленов Фробениуса, точные тождества).
  • Sage / PARI / mwrank: ранги эллиптических факторов, насыщение по одному простому (one_prime), формальные группы, p-адическая арифметика.
  • Magma (онлайн-калькулятор, V2.29-10): по одной верхней границе RankBounds на сечение. Для s = 1/5 граница повторена собственной реализацией 2-спуска для рода 2 в Sage (совпала с Magma на трёх контрольных моделях); для s = 1/4 модель K10 чётной степени — пока только Magma.
  • Реализации Шаботи: для обоих сечений — две независимые (Claude и Codex).
  • Не использованы: гипотеза чётности, BSD, конечность Ш, глобальные нижние оценки высоты (признаны ненадёжными в ходе аудита).

Остальные сечения до n = 65

Схема применена ко всем примитивным парам с n ≤ 65. Во всех одиннадцати случаях — ровно 4 локально разрешимых класса с одной вырожденной точкой в каждом наблюдение. Решающим оказывается ранг E₁ над k.

Корневое число +1 означает чётный коранг p∞-Сельмера (теоремы о p-чётности); вывод «ранг ≥ 2» требует ещё конечности Ш и потому остаётся оценкой. При ранге 2 = роду классический Шаботи над ℚ не работает, а квадратичный над ℚ требует ρ(J₂) ≥ 2, тогда как Endℚ(J₂) = ℤ (множители E₁, E₁σ неизогенны и переставляются Галуа). Готовых реализаций квадратичного Шаботи над вещественным квадратичным полем для условия x(P) ∈ ℚ не найдено.

Открытые вопросы

  • Независимая от Magma верхняя граница ранга для s = 1/4: модель K10 чётной степени требует полного 2-спуска для секстик (в Sage пока нет). Дополнительная проверка: классический Шаботи над ℚ на самой CJ₂ (rank 1 < род 2) — Magma Chabauty.
  • Независимая от Magma верхняя граница ранга — например, собственный спуск через изогению Ришело в Sage с контролем по известным ответам Magma.
  • Доказательство того, что «ровно 4 класса» выполняется для всех сечений, а не только наблюдается.
  • Метод для сечений с рангом 2: квадратичный Шаботи над числовым полем для условия x(P) ∈ ℚ.

Контекст

A. Auel, B. Singer, The algebraic geometry of 3-by-3 magic squares of squares, arXiv:2609.09351 (8 сентября 2026): поверхность магических квадратов из квадратов — особое полное пересечение шести квадрик в P⁸; группа автоморфизмов, диаграмма Ходжа, подрешётка Пикара ранга 518 (верхняя граница 544), проекции на поверхности дель Пеццо, K3 и Энриквеса. Сечения центрального креста — кривые на этой поверхности; закрытие отдельных сечений в статье не рассматривается (по аннотации).

Почему именно квадраты: в магическом 3×3 противоположные клетки дают в сумме удвоенный центр, так что каждая пара — решение xᵏ + yᵏ = 2wᵏ. При k ≥ 3 нетривиальных решений нет (Darmon–Merel, 1997), поэтому 3×3 из кубов и высших степеней невозможен; при k = 2 это окружность u² + v² = 2 — та самая параметризация B(s), H(s), на которой построены сечения (сводка — Grok, GROK_INFO_POWERS_AND_CENTER.md).

Поисковые эксперименты (не доказательства): свёртка бимагических квадратов 9×9 в 3×3 — 4,2 млн группировок, не более двух квадратных клеток из девяти (Codex, RESULT_FROM_CODEX_2026-09-11_BLOCK_FOLDING_9X9.md); поиск «крест + k углов» по решёткам Морделла–Вейля кривых углов — 80 сечений с n ≤ 500, точки решёток с |nⱼ| ≤ 5: ранги 317 кривых углов — 2 (150), 3 (140), 4 (24), ни одной меньше 2; невырожденных t с двумя и более квадратными углами не найдено (corners/).
