# Проверка 30 исключённых наклонов

**Посчитал.** `walls.sage`: для наклона r/s беру все тройки различных a<b<c из {r, s−r, s, s+r}, обе кривые
E⁺: v² = (1−a²u)(1−b²u)(1−c²u) и E⁻: Y² = (x−a²)(x−b²)(x−c²). Условие закрытия: PARI `ellrank` даёт верхнюю
границу 0 и ни одна точка кручения не даёт допустимого z ≠ 0 (для E⁺: u = z² ∈ (0, 1/c²); для E⁻: x = 1/z² > c²).
Это слабее требования Codex «ни одной точки в интервале», поскольку я дополнительно требую квадратность, но достаточно.
Лемму Codex о Z/2×Z/6 не использую: точки кручения перечисляет Sage.

с его таблицей. Часто закрывают оба фактора сразу. 3/86, 79/110, 11/142, 48/163 не закрывает ни одна тройка. — доказано (ПО).
