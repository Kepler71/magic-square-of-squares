## 5. Попутно: подъём в Q₇ автоматический, поэтому d_T и d_L — квадраты по модулю 7

**Статус: доказано.** Вывод ниже; проверил его пока один человек — Claude в этой сводке. Нужна перепроверка Codex или Fable. Впервые это заметили в `recompute/v3_a51edd4e` (t3c, t3e, t5b), в более раннем прогоне этого дня; здесь рассуждение из комментария t3c выведено заново. Теорема Codex это только усиливает, противоречия с ней нет.

(a) **При p ≡ 3 (mod 4) у z нет полюса.** Пусть v_p(z) < 0 и λ ∈ {r, s} — p-единица (такое λ есть, потому что r, s взаимно просты). Тогда 1±λz = ±λz·(1 ± (λz)⁻¹), и второй множитель — квадрат. По §1 противоположные клетки 1+λz и 1−λz лежат в одном классе, значит −1 — квадрат в Q_p. Противоречие.

(b) **Классы пар определяются вычетом z0 = z mod p.** Пусть p нечётно и z ∈ Z_p. Клетки 1±μz в сумме дают 2, поэтому хотя бы одна из них — единица. Класс пары общий (§1), поэтому он равен (0, c_μ), где c_μ — характер единичной клетки; если единицы обе, их характеры совпадают. По матрице §1: c_r = c_s = U, [T]_p = c_{r+s}, [L]_p = c_{r−s}, откуда c_{r+s}·c_{r−s} = c_r.

(c) **p = 7.** Положим w = μz0 mod 7. При w ∈ {0, ±1} c = +1 (единичная клетка равна 1 или 2, а 2 — квадрат mod 7). При w = ±2 c = −1 (3 и 6 — невычеты). При w = ±3 противоречие: 4 — вычет, 5 — невычет. Пусть x = rz0, y = sz0.
- Если c_r = c_s = −1, то x, y ∈ {±2}, и одна из сумм x±y равна ±4 = ∓3 — противоречие.
- Если c_r = c_s = +1 и оба x, y ненулевые, то {x+y, x−y} = {0, ±2}, произведение c равно −1 ≠ c_r — противоречие. Значит, одно из x, y равно 0, тогда x±y ∈ {0, ±1} и c_{r±s} = +1.

Итак, классы всех девяти клеток в Q₇ тривиальны. По §5 теоремы 7 не делит d_T d_L, поэтому **χ₇(d_T) = χ₇(d_L) = 1**. Причина, по которой p=7 особый: в F₇ нет трёхчленной АП из ненулевых квадратов.
