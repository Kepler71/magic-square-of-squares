# (15,8): нет ли пути проще квадратичного Шаботи

После замены t = (1+x)/(1−x) пять условий: F₀ = 289(1+x²) − 322x, F₄ = 289(1+x²), F₈ = 289(1+x²) + 322x,
L = 49 + 529x², U = 529 + 49x² (сверено с запиской Codex: тождества выведены заново, совпали).
При x = 0 все пять — квадраты, поэтому на всех производных кривых рода 1 есть рациональная точка.

**Произведения пар (10 кривых):** ранги 1, 1, 3, 3, 1, 1, 1, 3, 3, 2 — все доказаны (PARI ellrank, интервалы замкнуты).

**Чётные произведения** (F₄, L, U чётны; F₀·F₈ = (289(1+x²))² − 322²x² чётно) распадаются по u = x².
Все факторы рода 1: ранги 1–4, все доказаны. Кривая D Codex (F₀·F₈·L) — среди них, её факторы ранга 1,
что совпадает с его E1, E2.

**Вывод.** Ни один фактор рода 1 не даёт конечности, так что закрытие (15,8) требует метода уровня Шаботи.
Единственный другой путь, отличный от квадратичного Шаботи Codex: классический Шаботи на кривых рода 2
y² = u·g(u) из произведений четырёх форм (F₀F₄F₈L, F₀F₄F₈U, F₀F₈LU) — если ранг якобиана ≤ 1.
Для этого нужен 2-спуск в роде 2 (Magma или собственная реализация); в Sage и PARI его нет.
